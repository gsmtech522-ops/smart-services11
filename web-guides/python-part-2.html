سبق ۲: Variables اور Data Types

Variables — ڈیٹا کے ڈبے، جس کا نام ہے۔ Python میں dynamically typed — type خود سمجھ جاتی ہے۔ Data types: int، float، str، bool، None۔ Type conversion، f-strings، multiple assignment، constants — سب۔ یہ ہر پروگرام کی بنیاد ہے۔

1. Variables

name = "علی"
age = 25
height = 5.9
is_student = True
  • = assignment: right → left۔
  • نام: حروف، اعداد، underscore — ہندسے سے شروع نہیں۔
  • snake_case: Python convention — user_name۔

2. Data Types

  • int: پورے اعداد — 25، -10، 0۔
  • float: اعشاریہ — 5.9، 3.14۔
  • str: متن — "سلام"، 'hello'۔
  • bool: True / False (capital)۔
  • None: کوئی قدر نہیں — None۔
  • list, tuple, dict, set: collections — اگلے اسباق۔

3. type() — ٹائپ معلوم کریں

>>> type(25)
<class 'int'>
>>> type("سلام")
<class 'str'>
>>> type(True)
<class 'bool'>

4. Type Conversion

  • int(): int("25") → 25۔
  • float(): float("3.14") → 3.14۔
  • str(): str(25) → "25"۔
  • bool(): bool(0) → False، bool(1) → True۔

5. F-strings — جدید

name = "علی"
age = 25
print(f"سلام {name}، آپ کی عمر {age} سال ہے")

# حساب
print(f"اگلے سال {age + 1}")
print(f"دوگنا {age * 2}")

# Formatting
pi = 3.14159
print(f"Pi: {pi:.2f}")  # 3.14

6. کوڈ کی مکمل مثال

Python — variables.py
Terminal میں چلائیں: python variables.py

7. Naming Conventions

  • snake_case: variables — user_name۔
  • UPPER_CASE: constants — MAX_SIZE۔
  • PascalCase: classes — UserProfile۔
  • _private: داخلی — _helper۔
  • معنی خیز: x نہیں — count۔

8. اہم باتیں

  • ✅ f-string: ہمیشہ — format() یا % سے بہتر۔
  • ✅ type() سے چیک: debugging میں مدد۔
  • ✅ None: کوئی قدر نہیں — JavaScript کا null۔
  • ✅ Snake_case: Python convention۔
  • ✅ Multiple assignment: swap کے لیے بہترین۔
  • ✅ Type conversion: احتیاط سے — int("abc") error۔
