JavaScript گائیڈ

سبق ۲: ویری ایبلز (Variables) اور ڈیٹا ٹائپس

ویری ایبل ایک ڈبہ (Container) ہے جس میں آپ ڈیٹا رکھتے ہیں — نمبر، متن، یا true/false۔ JavaScript میں تین طرح سے ویری ایبل بنائے جاتے ہیں: var (پرانا)، let (تبدیل ہو سکتا ہے)، اور const (تبدیل نہیں ہو سکتا)۔

ویری ایبل کیا ہے؟

ویری ایبل ایک نامزد ڈبہ ہے جس میں ڈیٹا محفوظ کیا جاتا ہے۔ بعد میں اس نام سے ڈیٹا استعمال یا تبدیل کیا جا سکتا ہے۔

1. var، let، const کا فرق

  • var: پرانا طریقہ — block scope نہیں ہوتا، آج کل کم استعمال ہوتا ہے۔
  • let: جدید طریقہ — قدر بعد میں بدلی جا سکتی ہے۔
  • const: مستقل — ایک بار قدر دینے کے بعد بدلی نہیں جا سکتی۔

2. بنیادی ڈیٹا ٹائپس

  • Number: let age = 25;
  • String: let name = "احمد"; (سنگل یا ڈبل کوٹس)
  • Boolean: let isActive = true;
  • Undefined: let x; (قدر نہیں دی گئی)
  • Null: let y = null; (جان بوجھ کر خالی)
  • Object / Array: (اگلے اسباق میں)
