سبق ۳: Operators اور Input

Operators — حساب، comparison، logical، assignment۔ Arithmetic (+, -, *, /, //, %, **)، Comparison (==, !=, <, >)، Logical (and, or, not)، Assignment (=, +=, -=)۔ Input() — user سے data۔ String formatting — values show کرنا۔ یہ interactive programs کی بنیاد ہے۔

1. Arithmetic Operators

  • + جمع
  • - تفریق
  • * ضرب
  • / تقسیم (float)
  • // integer division (floor)
  • % modulus (باقی)
  • ** power

2. Comparison Operators

  • == برابر
  • != نا برابر
  • <, >, <=, >=
  • نتیجہ: True یا False۔

3. Logical Operators

  • and — دونوں سچ
  • or — کوئی ایک سچ
  • not — الٹ

4. Assignment Operators

  • = — assign
  • += — add + assign: x += 5 = x = x + 5
  • -=، *=، /=

5. Input() — User سے

name = input("اپنا نام: ")
age = int(input("عمر: "))  # ← int میں convert

print(f"سلام {name}!")
print(f"اگلے سال آپ {age + 1} سال کے")

اہم باتیں

  • ✅ / بمقابلہ //: 15/4=3.75، 15//4=3۔
  • ✅ % modulus: باقی — even/odd کے لیے۔
  • ✅ input() string: number کے لیے int()۔
  • ✅ and/or/not: keywords — JavaScript کے &&/||/! نہیں۔
  • ✅ += shorthand: x = x + 5 کا مختصر۔
  • ✅ Division by zero: چیک کریں — error سے بچیں۔
