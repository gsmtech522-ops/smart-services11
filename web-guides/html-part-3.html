سبق ۳: ٹیکسٹ فارمیٹنگ (Text Formatting)

جیسے MS Word میں bold، italic، underline — HTML میں بھی متن کو مختلف انداز دینے کے tags ہیں۔ Strong، em، b، i، u، mark، small، del، sub، sup — سب۔ Semantic (strong، em) اور presentational (b، i) کا فرق — accessibility کے لیے اہم۔

1. Bold — Strong بمقابلہ b

  • <strong>: اہم — semantic (screen reader زور دیتا)۔
  • <b>: صرف موٹا — کوئی معنی نہیں۔
  • ✅ ترجیح: <strong>۔

2. Italic — Em بمقابلہ i

  • <em>: emphasis — زور۔
  • <i>: صرف ترچھا — اصطلاحات، غیر ملکی الفاظ۔
  • ✅ ترجیح: <em>۔

3. مزید فارمیٹنگ Tags

  • <u> — underline۔
  • <mark> — highlight (پیلا)۔
  • <small> — چھوٹا (footer، copyright)۔
  • <del> — cross-out (پرانی قیمت)۔
  • <ins> — نیا شامل (نیچے لکیر)۔
  • <sub> — subscript (H₂O)۔
  • <sup> — superscript (x²)۔
  • <code> — code text۔
  • <pre> — preformatted (spacing محفوظ)۔
  • <blockquote> — quote۔
  • <q> — inline quote۔

4. کوڈ کی مکمل مثال

HTML — formatting.html
براؤزر میں رزلٹ:

▶ اس کوڈ کی وضاحت — قدم بہ قدم:

  • <strong> — متن کو اہم بتاتا ہے۔ براؤزر اسے موٹا دکھاتا ہے اور screen reader زور دے کر پڑھتا ہے۔
  • <em> — کسی لفظ پر زور دینے کے لیے؛ ظاہری شکل میں ترچھا ہوتا ہے۔
  • <del> — اور <mark> — del پر لکیر کٹ جاتی ہے (پرانی قیمت) اور mark متن کو پیلے رنگ سے نمایاں کرتا ہے (نئی قیمت)۔
  • <u> — متن کے نیچے لکیر۔ احتیاط: لنک بھی انڈر لائن ہوتے ہیں، اس لیے عام متن پر کم استعمال کریں تاکہ لنک کا دھوکا نہ ہو۔
  • <sub> — اور <sup> — sub متن کو نیچے (H₂O) اور sup اوپر (x²) کرتا ہے۔
  • <small> — چھوٹا متن، عموماً footer کی تحریر یا نوٹ کے لیے۔
  • <code> — کوڈ کا ٹکڑا، جو برابر چوڑائی والے فونٹ میں دکھتا ہے۔
  • <blockquote> — اور <q> — blockquote لمبا اقتباس الگ بلاک میں دکھاتا ہے، جبکہ q جملے کے اندر چھوٹا اقتباس ہے (براؤزر خود quotation marks لگاتا ہے)۔
  • <pre> — متن جیسا لکھا ہو ویسا ہی دکھاتا ہے، spaces اور نئی لائنوں سمیت؛ کوڈ کے بلاک کے لیے ضروری ہے۔

5. Semantic بمقابلہ Presentational

Semantic (بہتر) Presentational
<strong> <b>
<em> <i>

کیوں؟ screen reader semantic tags سے زور دیتے — accessibility بہتر۔

6. Nesting

✅ <p>یہ <strong><em>بولڈ اور ترچھا</em></strong> ہے۔</p>

❌ <p>یہ <strong><em>غلط</strong></em> ہے۔</p>

اہم باتیں

  • ✅ strong/em ترجیح: accessibility۔
  • ✅ Nesting: پہلے کھلا، آخر بند۔
  • ✅ mark: highlight — search results، اہم الفاظ۔
  • ✅ code + pre: code blocks — دونوں۔
  • ✅ Overuse سے بچیں: ضرورت پر — ورنہ اثر ختم۔

عمل / مشق (Task)

  1. ایک paragraph — 3 مختلف formatting۔
  2. پروڈکٹ قیمت — del + mark۔
  3. Code block — pre + code۔
  4. ایک quote — blockquote۔
