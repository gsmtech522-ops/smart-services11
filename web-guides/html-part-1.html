سبق ۱: HTML کا تعارف، Setup اور پہلا Program

HTML (HyperText Markup Language) ویب کی بنیادی زبان ہے — تمام ویب صفحات کا ڈھانچہ اسی سے بنتا ہے۔ اگر ویب سائٹ ایک عمارت ہے تو HTML اس کی اینٹیں اور ستون ہیں۔ CSS ڈیزائن، JavaScript فنکشنلٹی — لیکن بنیاد HTML ہے۔

1. HTML کیا ہے؟

  • Markup Language: پروگرامنگ نہیں — tags سے content کو structure دیتا ہے۔
  • ویب کی بنیاد: تمام براؤزرز (Chrome، Firefox، Edge، Safari) HTML سمجھتے ہیں۔
  • HyperText: لنکس سے صفحات جڑے — یہی "ویب" ہے۔
  • W3C Standard: بین الاقوامی معیار — سب براؤزرز پیروی کرتے ہیں۔
  • آفلائن: کوئی انٹرنیٹ ضروری نہیں — فائل براؤزر میں کھولیں۔

2. HTML کیوں ضروری ہے؟

  • Structure: کہاں heading، کہاں paragraph، کہاں image — سب HTML بتاتا ہے۔
  • Accessibility: screen readers HTML سے سمجھتے ہیں۔
  • SEO: سرچ انجن HTML پڑھتے ہیں۔
  • Foundation: React، Vue، Angular — سب آخر میں HTML بناتے ہیں۔
  • آسان: کوئی logic نہیں — صرف tags۔

5. کوڈ کی وضاحت — ہر لائن

  • <!DOCTYPE html> — HTML5 document کا اعلان۔
  • <html lang="ur" dir="rtl"> — root، زبان اردو، سمت RTL۔
  • <head> — meta info (براؤزر کے لیے، نہ دکھے)۔
  • <meta charset="UTF-8"> — اردو حروف صحیح دکھیں۔
  • <meta name="viewport" ...> — موبائل responsive۔
  • <title> — براؤزر ٹیب کا عنوان۔
  • <body> — مرکزی مواد (جو دکھے)۔
  • <h1> — بڑی heading۔
  • <p> — paragraph۔

6. Tags کی اقسام

  • Opening Tag: <p>
  • Closing Tag: </p>
  • Self-closing: <br>، <img>، <hr>
  • Element: <p>متن</p> — مکمل
  • Attribute: <p class="text"> — اضافی info

7. اہم باتیں

  • ✅ Indentation: nested tags — اندر، 2-4 spaces۔
  • ✅ Lowercase: tags — <p> نہ <P>۔
  • ✅ DOCTYPE: ہمیشہ پہلی لائن۔
  • ✅ lang + dir: اردو کے لیے lang="ur" dir="rtl"۔
  • ✅ charset: UTF-8 — اردو کے لیے لازمی۔
  • ✅ Test: ہر تبدیلی پر براؤزر refresh۔
