سبق ۳: آپریٹرز (Operators) اور کنڈیشنز (if, else, switch)

آپریٹرز سے حساب، موازنہ اور منطقی فیصلے کیے جاتے ہیں۔ کنڈیشنز (if, else, switch) سے پروگرام کو فیصلہ کرنے کی طاقت ملتی ہے — 'اگر ایسا ہو تو یہ کرو، ورنہ وہ کرو'۔

1. Arithmetic Operators (حسابی)

  • + جمع، - تفریق، * ضرب، / تقسیم
  • % باقی (Modulus) — 10 % 3 = 1
  • ** طاقت — 2 ** 3 = 8

2. Comparison Operators (موازنہ)

  • == برابر (قدر)، === برابر (قدر + ٹائپ) — === بہتر ہے
  • !=, !== نا برابر
  • >, <, >=, <=

3. Logical Operators (منطقی)

  • && اور (دونوں سچ ہوں)
  • || یا (کوئی ایک سچ ہو)
  • ! نہیں (الٹ)

4. if / else if / else

5. switch — کئی صورتوں کے لیے

اہم باتیں اور قواعد

  • == بمقابلہ ===: "5" == 5 سچ ہے، لیکن "5" === 5 جھوٹ — ہمیشہ === استعمال کریں۔
  • Truthy / Falsy: 0, "", null, undefined, NaN جھوٹے ہیں — باقی سب سچے۔
  • Ternary: let result = marks >= 50 ? "پاس" : "فیل";
  • switch میں break: بھولنے سے اگلا case بھی چل جائے گا (fall-through)۔

عمل / مشق (Task)

  1. ایک ویری ایبل میں نمبر رکھیں اور if/else سے چیک کریں کہ وہ جفت (Even) ہے یا طاق (Odd)۔
  2. ایک switch بنائیں جو مہینے کا نمبر لے کر اس کا نام دکھائے۔
