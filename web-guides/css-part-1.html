سبق ۱: CSS کا تعارف اور شامل کرنے کے طریقے (Introduction to CSS)

CSS (جس کا پورا نام Cascading Style Sheets ہے) کا استعمال HTML کے ذریعے بنائے گئے ڈھانچے کو خوبصورت، رنگین اور باقاعدہ ڈیزائن دینے کے لیے کیا جاتا ہے۔ اگر HTML کسی عمارت کی بنیادی اینٹیں ہیں، تو CSS اس کی پینٹنگ ہے۔

CSS شامل کرنے کے 3 طریقے

HTML میں CSS کو بنیادی طور پر تین طریقوں سے لکھا جا سکتا ہے:

  • Inline CSS: کسی ایک مخصوص HTML ٹیگ کے اندر style ایٹریبیوٹ کا استعمال کرتے ہوئے۔
  • Internal CSS: HTML فائل کے <head> حصے میں <style> ٹیگ کے اندر۔
  • External CSS: (بہترین طریقہ) ایک الگ .css فائل style.css کے نام سے بنا کر اسے HTML پیج کے <head> میں <link> ٹیگ کے ذریعے جوڑنا۔

CSS کا بنیادی طریقہ کار (Syntax)

CSS میں کسی بھی ایلیمنٹ کو ڈیزائن کرنے کا فارمیٹ یوں ہوتا ہے:

selector { property: value; }

  • Selector: جس HTML ایلیمنٹ کو آپ ڈیزائن کرنا چاہتے ہیں (جیسے h1, p, body)۔
  • Property: وہ خصوصیت جسے آپ بدلنا چاہتے ہیں (جیسے color, background-color, font-size)۔
  • Value: وہ قیمت یا رنگ جو آپ لاگو کرنا چاہتے ہیں (جیسے blue, 20px)۔

Inline CSS کی مثال

HTML کوڈ ایڈیٹر

اوپر کوڈ میں heading ٹیگ کے اندر style ایٹریبیوٹ کا استعمال کر کے ہیڈنگ کو رنگین بنایا گیا ہے۔ یہ Inline CSS کی مثال ہے۔

Internal CSS کی مثال

HTML کوڈ ایڈیٹر
براؤزر میں رزلٹ:

اوپر کے کوڈ میں <head> سیکشن میں <style> ٹیگ کے اندر CSS کا کوڈ لکھا گیا ہے، جیسے body { background-color: blue; } اور h1 { color: red; }۔ باقی سارا کوڈ HTML ہے۔

External CSS کی مثال

External CSS میں CSS کی الگ فائل بنانی ہوتی ہے، style.css، اور اس میں الگ سے CSS کا کوڈ لکھا جاتا ہے۔ HTML کی فائل index.html میں اس کا سورس <head> سیکشن میں <link> ٹیگ کے ذریعے ڈالا جاتا ہے۔ پہلے ایک HTML فائل بنائیں: index.html

index.html

HTML کوڈ ایڈیٹر
براؤزر میں رزلٹ:

style.css

CSS کوڈ ایڈیٹر
براؤزر میں رزلٹ:

index.html کے <head> سیکشن میں CSS کی لوکل فائل کا لنک دیا گیا ہے۔

  • <link>: ٹیگ
  • rel, href: ایٹریبیوٹس
  • "style.css": CSS فائل کا راستہ
  • stylesheet: فائل کی قسم

CSS فائل کا کوڈ

  • body, h1: سلیکٹرز
  • background-color, color: پراپرٹیز
  • red, blue: ویلیوز

اہم باتیں اور قواعد

  • External CSS کا فائدہ: ایک ہی فائل سے پورا پروجیکٹ ڈیزائن کرنے کا سب سے بڑا فائدہ یہ ہے کہ آپ صرف ایک style.css فائل میں تبدیلی کر کے اپنی ویب سائٹ کے تمام HTML پیجز کا ڈیزائن ایک ساتھ بدل سکتے ہیں۔
  • سیمیکولن (;) کا استعمال: ہر CSS پراپرٹی اور ویلیو کے بعد سیمیکولن (;) لگانا ضروری ہے، ورنہ اس کے بعد والا کوڈ کام نہیں کرے گا۔

نوٹ

اگر آپ کی CSS فائل کا نام مختلف ہے تو HTML فائل کے <head> سیکشن میں <link> ٹیگ کے اندر نام تبدیل کرنا ہوگا۔ اور اگر آپ کی CSS فائل کسی اور فولڈر میں ہے تو راستہ کچھ یوں ہوگا: foldername/style.css۔ CSS فائل میں HTML کا کوڈ نہیں ہوگا بلکہ اس کا اپنا کوڈ ہوگا۔ CSS فائل میں دیگر ٹیگز جیسے پیراگراف وغیرہ کو بھی ڈیزائن کیا جا سکتا ہے اور مزید پراپرٹیز بھی شامل کی جا سکتی ہیں۔
