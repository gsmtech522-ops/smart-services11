Python گائیڈ

سبق ۱: Python کا تعارف، Setup اور پہلا Program

Python دنیا کی سب سے مقبول اور آسان پروگرامنگ زبان ہے۔ ویب ڈویلپمنٹ، Data Science، AI/ML، Automation، scripting — ہر جگہ استعمال۔ سادہ syntax، بڑی community، 400k+ packages — beginner کے لیے بہترین۔ اس سبق میں install، پہلا program، اور بنیادیات۔

1. Python کیا ہے؟

  • High-level Language: انسان کے قریب — پڑھنا آسان۔
  • Interpreted: compile نہیں — line by line چلتی ہے۔
  • Dynamically Typed: variable کا type خود سمجھ لیتی ہے۔
  • Multi-paradigm: OOP، functional، procedural — سب۔
  • Cross-platform: Windows، Mac، Linux — ہر جگہ۔
  • Batteries included: standard library بہت بڑی۔

2. Python کہاں استعمال؟

  • Web Development: Django، Flask، FastAPI۔
  • Data Science: Pandas، NumPy، Matplotlib۔
  • AI/Machine Learning: TensorFlow، PyTorch، scikit-learn۔
  • Automation: scripts، web scraping، bots۔
  • DevOps: Ansible، cloud scripts۔
  • Scientific Computing: research، simulation۔
  • Game Development: Pygame۔
  • Desktop Apps: Tkinter، PyQt۔

3. Python کیوں؟

  • ✅ آسان: JavaScript سے سیکھنا آسان — سادہ syntax۔
  • ✅ Community: بہت بڑی — help آسانی سے ملے گی۔
  • ✅ Jobs: demand زیادہ — AI کا دور۔
  • ✅ Versatile: ہر domain میں۔
  • ✅ Packages: PyPI پر 400k+ libraries۔
  • ✅ Reading: code پڑھنا آسان — team work۔

4. Setup

قدم 1: python.org سے Python 3.12+ نصب کریں۔

قدم 2: Install کے وقت "Add Python to PATH" ضرور چیک کریں (Windows)۔

قدم 3: Terminal میں چیک کریں:

python --version
pip --version

5. Editor

  • VS Code: best — Python extension کے ساتھ۔
  • PyCharm: full IDE — بہت features۔
  • Jupyter Notebook: data science کے لیے۔
  • Thonny: beginners کے لیے — سادہ۔
  • IDLE: Python کے ساتھ آتا ہے۔

6. پہلا Program

hello.py بنائیں:

Python — hello.py
Terminal میں چلائیں: python hello.py

7. Python کا بنیادی ڈھانچہ

  • Indentation: 4 spaces — Python میں لازمی۔
  • Comments: # single line۔
  • Case-sensitive: name ≠ Name۔
  • Line = Statement: سیمیکولن ضروری نہیں۔
  • Strings: سنگل یا ڈبل quotes — دونوں۔

8. Interactive Shell (REPL)

python
>>> 2 + 3
5
>>> "سلام"
'سلام'
>>> exit()

9. Test — اپنی سمجھ

Python — test.py
Terminal میں چلائیں: python test.py

اہم باتیں

  • ✅ Indentation لازمی: 4 spaces — Python کی پہچان۔
  • ✅ f-string: variable کو string میں — f"سلام {name}"۔
  • ✅ print بہترین دوست: debugging کے لیے۔
  • ✅ VS Code: extension کے ساتھ — auto-complete، run۔
  • ✅ REPL: python سے — experiment کریں۔

عمل / مشق (Task)

  1. Python نصب کریں — version چیک کریں۔
  2. VS Code نصب — Python extension۔
  3. hello.py بنائیں — اپنا تعارف۔
  4. f-string سے مختلف 5 prints۔
  5. REPL میں 5 calculations۔
