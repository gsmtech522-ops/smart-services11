سبق ۲: CSS Selectors — Class, ID اور ایلیمنٹس

CSS میں Selectors کا کام یہ طے کرنا ہے کہ کون سے HTML ایلیمنٹ پر کون سا ڈیزائن یا اسٹائل لاگو ہوگا۔ اگر آپ پیج کے تمام پیراگراف کا رنگ بدلنا چاہتے ہیں، یا صرف کسی ایک بٹن کا سائز بڑھانا چاہتے ہیں، تو اس کے لیے درست Selector کا انتخاب ضروری ہے۔

بنیادی CSS Selectors

  1. Element Selector (ٹیگ کا نام): یہ براہِ راست HTML ٹیگ کے نام سے کام کرتا ہے اور پیج پر موجود ان تمام ٹیگز کا ڈیزائن ایک ساتھ بدل دیتا ہے۔
    مثال: p { color: blue; } (پیج کے تمام پیراگراف کا رنگ نیلا ہو جائے گا)
  2. Class Selector (کلاس، ڈاٹ . کے ساتھ): جب آپ کو کسی ایک یا ایک سے زیادہ مخصوص ایلیمنٹس کا ڈیزائن باقی ایلیمنٹس سے الگ کرنا ہو تو class کا استعمال کیا جاتا ہے۔ HTML میں class="name" لکھا جاتا ہے اور CSS میں اس کے نام کے آگے ڈاٹ (.) لگایا جاتا ہے۔
    مثال: .card { background-color: white; }
  3. ID Selector (آئی ڈی، ہیش # کے ساتھ): id کسی پیج میں صرف ایک ہی ایلیمنٹ کو دی جاتی ہے (یہ کسی ایک ایلیمنٹ کی منفرد شناخت ہوتی ہے)۔ CSS میں اس کے نام کے آگے ہیش (#) کا نشان لگایا جاتا ہے۔
    مثال: #main-header { font-size: 24px; }

کوڈ کی مثال

index.html

HTML کوڈ ایڈیٹر
براؤزر میں رزلٹ:

style.css

CSS کوڈ ایڈیٹر
براؤزر میں رزلٹ:
  • کلاس بنام آئی ڈی (Class vs ID): ایک ہی کلاس کا نام آپ پیج کے متعدد HTML ایلیمنٹس کو دے سکتے ہیں، لیکن ایک ID نام پورے پیج میں صرف ایک ہی ایلیمنٹ کے لیے استعمال ہونا چاہیے۔
  • نام کا انتخاب: کلاس یا ID کا نام دیتے وقت چھوٹے حروف (small letters) استعمال کریں اور الفاظ کے درمیان ڈیش (-) لگائیں، جیسے .main-btn یا #site-logo۔
