سبق ۳: CSS Colors, Backgrounds اور Fonts

کسی بھی ویب پیج کی خوبصورتی، پڑھنے میں آسانی اور ڈیزائننگ کا دارومدار بنیادی طور پر رنگوں کے انتخاب (Colors)، بیک گراؤنڈ (Backgrounds) اور تحریر کے انداز (Fonts) پر ہوتا ہے۔ اس سبق میں ہم یہی تینوں بنیادی پہلو سیکھیں گے۔

1. CSS Colors (رنگ دینے کے طریقے)

CSS میں رنگ مختلف طریقوں سے دیے جا سکتے ہیں:

  • رنگوں کے نام (Color Names): جیسے red, blue, green وغیرہ۔
  • HEX Codes (چھ ہندسوں کا کوڈ): جیسے #ff0000 (سرخ) یا #008000 (سبز)۔
  • RGB / RGBA: rgb(255, 0, 0)۔ اگر شفافیت (Opacity) بھی شامل کرنی ہو تو RGBA استعمال ہوتا ہے، جیسے rgba(255, 0, 0, 0.5)۔

2. CSS Backgrounds (پس منظر کا ڈیزائن)

کسی ایلیمنٹ یا پورے پیج کا پس منظر سیٹ کرنے کے لیے درج ذیل خصوصیات استعمال ہوتی ہیں:

  • background-color: پس منظر میں رنگ بھرنے کے لیے۔
  • background-image: پس منظر میں تصویر لگانے کے لیے (url('image.jpg'))۔
  • background-repeat: تصویر کو بار بار دہرانے سے روکنے کے لیے (no-repeat)۔
  • background-size: تصویر کا سائز فٹ کرنے کے لیے (cover یا contain)۔

3. CSS Fonts اور Typography (تحریر کی اسٹائلنگ)

متن کو پڑھنے میں آسان اور خوبصورت بنانے کے لیے:

  • font-family: فونٹ کی قسم یا انداز طے کرنے کے لیے (مثلاً Arial, Tahoma, sans-serif)۔
  • font-size: تحریر کا سائز طے کرنے کے لیے (پکسلز px یا rem میں)۔
  • font-weight: الفاظ کو موٹا (Bold) یا باریک کرنے کے لیے (bold یا normal)۔
  • text-align: متن کی سمت سیٹ کرنے کے لیے (right, left, center)۔

اہم باتیں اور قواعد

  • Fallback Fonts: font-family میں ہمیشہ ایک سے زیادہ فونٹس دیں (جیسے 'Tahoma', sans-serif) تاکہ اگر صارف کے کمپیوٹر میں پہلا فونٹ موجود نہ ہو تو دوسرا فونٹ خودکار طور پر چالو ہو جائے۔
  • RGBA کا فائدہ: rgba() استعمال کرنے سے آپ بیک گراؤنڈ کو ہلکا شیشے جیسا (Semi-transparent) بنا سکتے ہیں۔
