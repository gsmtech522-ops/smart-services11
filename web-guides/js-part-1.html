JavaScript گائیڈ

سبق ۱: جاوا اسکرپٹ کا تعارف، Setup اور پہلا Program

اگر HTML کسی ویب سائٹ کا ڈھانچہ (Skeleton) ہے اور CSS اس کا روپ/ڈیزائن (Styling) ہے، تو JavaScript اس کا دماغ (Brain) ہے۔ یہ ویب پیج پر کلک کرنے، ڈیٹا پروسیس کرنے، اینیمیشنز چلانے اور بغیر پیج ریفریش کیے ڈیٹا لوڈ کرنے کا کام کرتی ہے۔

JavaScript کیا ہے؟

JavaScript (JS) ایک پروگرامنگ زبان ہے جو براؤزر میں چلتی ہے۔ یہ ویب پیج کو متحرک (Dynamic) بناتی ہے — بٹن کا کلک سنبھالنا، ڈیٹا کا حساب کرنا، HTML کو تبدیل کرنا، اور صارف کے ساتھ تعامل کرنا۔

HTML میں JavaScript شامل کرنے کے 3 طریقے

  • Inline: کسی ٹیگ کے اندر onclick="..." وغیرہ (سادہ کاموں کے لیے)۔
  • Internal: HTML کے اندر <script> ... </script> ٹیگ میں۔
  • External: (بہترین طریقہ) الگ main.js فائل بنا کر <script src="js/main.js"></script> سے جوڑنا — </body> سے بالکل پہلے۔

Console کہاں ہے؟

براؤزر میں F12 دبائیں یا right-click → Inspect → Console ٹیب کھولیں۔ console.log() کا نتیجہ وہاں نظر آئے گا۔

اہم باتیں اور قواعد

  • سیمیکولن (;): ہر statement کے بعد لگانا اچھی عادت ہے (لازمی نہیں، لیکن محفوظ)۔
  • کیس سینسیٹو (Case-Sensitive): console اور Console مختلف ہیں۔
  • Comments: // ایک لائن، /* ... */ کئی لائنیں۔
  • External بہتر: کوڈ کو الگ فائل میں رکھیں تاکہ HTML صاف رہے۔
