سبق ۲: بنیادی ٹیگز اور ساخت (Basic Tags & Structure)

HTML میں ہر چیز tags سے — ہر tag براؤزر کو بتاتا ہے کہ content کیسے دکھانا ہے۔ Opening tag، closing tag، element، attribute — سب سمجھیں۔ Headings (h1-h6)، paragraphs (p)، line breaks (br)، horizontal rules (hr) — سب سے زیادہ استعمال ہونے والے tags۔

1. Tag کا ڈھانچہ

<tagname attribute="value">content</tagname>
    │       │              │        │
 Opening  Attribute      Content   Closing

2. Headings — h1 سے h6

  • h1: سب سے بڑی — صفحے کا مرکزی عنوان (ایک ہی ہو)۔
  • h2: section headings۔
  • h3-h6: مزید ذیلی۔

اہم: سائز کے لیے نہیں — hierarchy کے لیے۔ CSS سے سائز بدلیں۔

3. Paragraph

<p>یہ ایک پیراگراف ہے۔ اردو میں طویل متن یہاں آتا ہے۔</p>

4. Line Break اور Horizontal Rule

  • <br> — نئی لائن (self-closing)۔
  • <hr> — افقی لکیر (self-closing)۔

5. کوڈ کی مکمل مثال

HTML — basic-tags.html
براؤزر میں رزلٹ:

▶ اس کوڈ کی وضاحت — قدم بہ قدم:

  • <h1> — صفحے کا مرکزی عنوان۔ پورے صفحے پر صرف ایک بار استعمال کریں؛ براؤزر اسے سب سے بڑا اور موٹا دکھاتا ہے۔
  • <p> — ہر پیراگراف الگ بلاک بنتا ہے۔ اوپر نیچے خالی جگہ براؤزر خود چھوڑ دیتا ہے، آپ کو کچھ نہیں کرنا پڑتا۔
  • <hr> — ایک افقی لکیر کھینچتا ہے تاکہ صفحے کے دو حصے الگ نظر آئیں۔ اس کا closing tag نہیں ہوتا۔
  • <h2> — ذیلی عنوان۔ یہ h1 کے نیچے کے حصوں کے لیے ہے، اس لیے مثال میں دو بار آیا ہے۔
  • <br> — پیراگراف کے اندر ہی نئی لائن شروع کرتا ہے۔ نیا پیراگراف نہیں بنتا، صرف لائن بدلتی ہے۔
  • رزلٹ: بڑا عنوان، پھر لکیر، پھر دو سرخیاں؛ پہلے پیراگراف کا متن دو لائنوں میں ٹوٹا نظر آئے گا۔

6. Self-closing Tags

  • <br> — line break
  • <hr> — horizontal rule
  • <img> — image
  • <input> — form field
  • <meta> — metadata
  • <link> — external file

7. Nesting — ترتیب اہم

✅ صحیح:
<p><strong>بولڈ متن</strong></p>

❌ غلط (crossed tags):
<p><strong>بولڈ</p></strong>

پہلے کھلا = آخر میں بند۔

8. Attributes

<a href="page.html" target="_blank">لنک</a>
    │    │       │      │
  Tag  Attr1   Value1  Attr2  Value2

اہم باتیں

  • ✅ h1 صرف ایک: صفحے کا مرکزی عنوان۔
  • ✅ Hierarchy: h1 → h2 → h3 (نہ چھوڑیں)۔
  • ✅ br/ hr خود بند: کوئی closing نہیں۔
  • ✅ Nesting صحیح: پہلے کھلا آخر بند۔
  • ✅ Indentation: nested tags اندر۔

عمل / مشق (Task)

  1. ایک صفحہ بنائیں — h1، h2، 3 paragraphs۔
  2. Paragraphs میں br سے line breaks۔
  3. 2 sections — hr سے الگ۔
  4. Nesting — strong + em ایک ساتھ۔
