How to Enable Qualcomm Diagnostic (Diag) Mode on Android

Type
Step-by-Step Guide
Level
Advanced
Time
~10 minutes
Applies to
Xiaomi, Redmi, POCO, Vivo, iQOO, Oppo, Realme, Samsung Snapdragon, Lenovo
Last updated
YYYY-MM-DD

Advanced Qualcomm servicing — IMEI repair, QCN backup/restore, baseband repair, network recalibration — requires your PC to talk directly to the phone's Qualcomm modem. To enable that, the device must be in Qualcomm Diagnostic Mode (Diag Mode). Once enabled, Windows Device Manager detects the device as Qualcomm HS-USB Diagnostics 900E / 9091 / 9025 (COMxx).

Legal warning: Diag mode is used for your own device or a device you are authorized to service. IMEI modification is illegal in most countries. Only use these methods for backup, restore, and repair of devices you own.

Reference

  1. 1. Prerequisites

    • Qualcomm USB Drivers installed on your PC (both QDLoader 9008 and Diagnostics drivers).
    • USB Debugging enabled (Settings → Developer Options → USB Debugging).
    • ADB & Fastboot installed on your PC.

  2. 2. Method 1 — Dial pad secret codes (no root required)

    The simplest method — works on many stock and older Qualcomm devices.

    1. Open the Phone Dialer app on the device.
    2. Enter the secret code for your brand:
    BrandCode / Action
    Xiaomi / Redmi / POCO*#*#717717#*#* or *#*#13491#*#*
    Vivo / iQOO*#558# → Quality verification test → Port → tick "Development Port"
    Oppo / Realme*#801# or *#6776# → Engineer Mode → Switch Diag ON
    Generic Qualcomm / Lenovo*#*#197328640#*#* or *#*#2432546#*#*
    1. If successful, a toast message like "Diag Mode Enabled" appears, or an Engineer Menu opens.
    2. Connect the phone to PC via USB and check Device Manager → Ports (COM & LPT).

  3. 3. Method 2 — Enable Diag Mode via ADB (root required)

    If dial codes are blocked by the OEM, force-enable the Diagnostic port using ADB on a rooted device.

    1. Connect the phone with USB Debugging on.
    2. Open Command Prompt or PowerShell.
    3. Verify the device is recognized:
    adb devices
    1. Authorize the USB debugging prompt on the phone screen if requested.
    2. Grant root access:
    adb shell su

    Approve the SuperSU / Magisk prompt on the phone.

    1. Run the setprop command matching your device:

    Command Set A — Standard Qualcomm devices:

    setprop sys.usb.config diag,adb

    Command Set B — Xiaomi / Redmi / OnePlus:

    setprop sys.usb.config diag,diag_mdm,adb

    Command Set C — Stubborn or dual-SIM devices:

    setprop sys.usb.config rndis,diag,adb
    1. As soon as you press Enter, Windows plays a device connection sound, and Qualcomm HS-USB Diagnostics appears in Device Manager.

  4. 4. Method 3 — Servicing tools (one-click, no root)

    If you have no root access and secret codes are disabled, modern servicing tools can temporarily enable Diag mode via ADB or Fastboot.

    UnlockTool / Miracle Box / UFI Box / EMT:

    1. Connect the phone in ADB mode (USB Debugging ON).
    2. Go to the Qualcomm / Special tab in your tool.
    3. Click Enable Diag / Enable Diag (No Root).

    Fastboot method (Xiaomi / POCO):

    1. Boot into Fastboot (Volume Down + Power).
    2. Open the tool (e.g. UnlockTool or Xiaomi Special Tools).
    3. Click Enable Diag in Fastboot Mode.
    4. The tool sends a temporary payload to open the Diag port — no data is wiped.

  5. 5. Method 4 — Samsung Snapdragon Diag codes

    Samsung devices powered by Snapdragon processors use different hidden menus:

    1. Open the Samsung phone dialer.
    2. Dial *#0808# to open USB Settings.
    3. Select DM + MODEM + ADB or RNDIS + DM + ADB.
    4. Tap OK / Reboot.
    5. Alternative code: dial *#9090# → Diagnostic Configuration → choose USB.

  6. 6. Verify Diag Mode connection on PC

    1. Press Win+X → Device Manager.
    2. Expand Ports (COM & LPT).
    3. Look for Qualcomm HS-USB Diagnostics 900E (or 9091, 9025, 901D) followed by a COM port number, e.g. COM12.
    4. If a yellow warning icon appears, right-click → Update driver → Browse → Let me pick from a list… → choose Qualcomm HS-USB Diagnostics from the installed driver package.

  7. 7. Disable Diag Mode (return to normal USB)

    Once servicing is complete, always turn off Diag mode so USB file transfer works normally.

    • Via Dialer: re-enter the dial code (e.g. *#*#717717#*#* on Xiaomi) to toggle it OFF.
    • Via ADB (root):
    adb shell su
setprop sys.usb.config mtp,adb
    • Via Phone Settings: unplug USB → Settings → Developer Options → toggle USB Debugging OFF and ON, or select File Transfer (MTP) from the USB notification.

  8. 8. Troubleshooting

    ProblemFix
    Dial code does nothingOEM blocked it. Use ADB (Method 2) or a servicing tool (Method 3).
    Device not showing Diag in Device ManagerMissing Qualcomm Diagnostics driver. Install full Qualcomm USB driver package.
    Port appears with yellow warningRight-click → Update driver → manual selection → Qualcomm HS-USB Diagnostics.
    setprop command ignoredRoot not granted, or device not on the correct Android version. Try Command Set B or C.
    Diag mode works but QCN tool can't connectWrong COM port selected — check which COM the Diag port uses in Device Manager.
    Phone becomes unresponsive after DiagReboot the phone. Some modem states need a fresh boot.

  10. 10. Best practices

    • ✅ Only enable Diag mode when actively servicing a device.
    • ✅ Disable Diag mode before returning the phone to normal use.
    • ✅ Verify the port in Device Manager before running QCN/IMEI tools.
    • ✅ Back up EFS/QCN before any repair operation (see related guides).
    • ✅ Never modify IMEI on someone else's device — it's illegal.
    • ✅ Keep a note of the COM port number for the servicing tool.

Tip: after every reboot, Diag mode resets to normal USB mode — you must re-enable it each session. Use the ADB setprop commands for quickest re-enable on rooted devices.
