How to Install Qualcomm Snapdragon USB Drivers on Windows

Type
Step-by-Step Guide
Level
Beginner
Time
~10 minutes
Applies to
Windows 7, 8, 10, 11
Last updated
YYYY-MM-DD

When dealing with software repairs, firmware flashing, network unlocking or restoring devices powered by Qualcomm Snapdragon processors, having the correct drivers installed on your PC is critical. Qualcomm devices use two main servicing modes:

  • Emergency Download Mode (EDL): used for deep flashing, unbricking and system recovery via the Qualcomm HS-USB QDLoader 9008 driver.
  • Diagnostic Mode (Diag): used for advanced tasks like IMEI repair, QCN backup/restore, and network recalibration via the Qualcomm HS-USB Diagnostics 900E / 9091 / 9025 driver.

Without these drivers, servicing tools like QFIL, Miracle Box, UnlockTool, UFI Box or specialized IMEI tools will fail to detect your phone.

Reference

  1. 1. Prerequisites (crucial step)

    Before manual installation on Windows 8, 10 or 11, you must disable Driver Signature Enforcement. Windows blocks unsigned drivers by default, causing the QDLoader or Diag driver install to fail or show a yellow warning icon.

  2. 2. Method 1 — Automatic installation (recommended)

    The official Qualcomm Driver setup wizard handles both QDLoader 9008 and Diagnostic port configurations automatically.

    1. Download & extract: download the Qualcomm USB Driver package and extract the .rar file with WinRAR or 7-Zip. Trusted sources include qdloader.com and the official Qualcomm developers site.
    2. Launch setup: open the extracted folder and double-click the setup executable (e.g. Qualcomm_USB_Driver_v1.0.exe) as Administrator.
    3. Select setup type: on the initial screen, choose "WWAN-DHCP is used to get IPAddress" and click Next.
    4. License agreement: click Next on the Welcome screen, accept the terms, click Next.
    5. Install: click Install to copy driver files to your system.
    6. Finish & reboot: click Finish and restart your PC to apply system updates.

  3. 3. Method 2 — Manual install via Device Manager

    If the device appears in Device Manager as QHUSB_BULK, QUSB_BULK, Android, or an Unknown Device with a yellow exclamation mark (or an unrecognized Serial/COM port), the automatic installer did not bind the driver correctly. Force-install it manually.

    1. Extract driver package: ensure the raw Qualcomm driver files (containing the .inf configuration files) are extracted to an accessible folder.
    2. Open Device Manager: press Win+X → Device Manager.
    3. Locate device: look for QHUSB_BULK or QUSB_BULK under Other devices (or under Ports (COM & LPT)).
    4. Update driver: right-click the device → Update driver → Browse my computer for drivers.
    5. Manual pick: click Let me pick from a list of available drivers on my computer. If prompted, tick Show all devices → Next → Have Disk….
    6. Locate driver file: click Browse, navigate to your extracted Qualcomm driver folder, open the folder for your Windows architecture (e.g. Win10 > x64 or Free), and select the .inf file (typically qcser.inf or qcdrivers.inf) → Open → OK.
    7. Select port driver:
      • For EDL / Flashing Mode: choose Qualcomm HS-USB QDLoader 9008.
      • For IMEI Repair / Diag Mode: choose Qualcomm HS-USB Diagnostics 900E (or the Diag Port matching your chipset, e.g. 9091 or 9025).
    8. Confirm installation: if Windows Security warns "Windows can't verify the publisher of this driver software", click "Install this driver software anyway".
    9. Complete setup: click Close when installation succeeds.

    Code 10 / Code 31 error: if a warning icon appears after installation while the device is disconnected, you can safely ignore it. The driver requires an active EDL or Diag connection to initialize properly.

  4. 4. Verify EDL mode connection

    1. Open Device Manager and expand Ports (COM & LPT).
    2. Connect the Qualcomm device in EDL mode (via test points, hardware key combos, or an EDL cable).
    3. Check Device Manager — you should see Qualcomm HS-USB QDLoader 9008 (COMxx) listed clearly under Ports, without any yellow warning icon.

  5. 5. Verify Diag (Diagnostic) mode connection

    1. Enable Diag mode on your device via dialer code (e.g. *#*#717717#*#*), AT commands, root access, or a servicing tool — see Enable Qualcomm Diag Mode.
    2. Connect the phone to PC via USB.
    3. In Device Manager → Ports (COM & LPT) you should see Qualcomm HS-USB Diagnostics (COMxx) (e.g. 900E, 9091, or 9025), ready for IMEI repair and diagnostics.

  6. 6. Troubleshooting

    ProblemFix
    Driver install fails on Windows 10/11Disable Driver Signature Enforcement first, reboot, then retry.
    QHUSB_BULK shows with yellow warningForce-install via Device Manager → Have Disk → qcser.inf.
    Code 10 / Code 31 warningSafe to ignore if the device is disconnected. Reconnect in EDL / Diag mode.
    Diag port shows "unrecognized"Wrong .inf selected, or wrong architecture (x86 vs x64). Re-do method 2 with the correct folder.
    QDLoader not appearing when entering EDLWrong driver bound. Uninstall current driver, replug with driver signature enforcement disabled, and reinstall.
    Multiple Qualcomm devices conflictingClean out older driver entries first via pnputil /enum-drivers and delete by name.

  7. 7. Complete command reference

    # ---- Enter Windows Test Mode (if unsigned driver blocked) ----
# 1. Hold Shift → click Restart → Troubleshoot → Advanced → Startup Settings → Restart
# 2. Press 7 or F7 to "Disable driver signature enforcement"

# ---- Verify driver after install ----
# Device Manager → Ports (COM & LPT)
# Expected entries:
#   Qualcomm HS-USB QDLoader 9008 (COMx)      <- EDL mode
#   Qualcomm HS-USB Diagnostics 900E (COMx)   <- Diag mode
#   Qualcomm HS-USB Diagnostics 9091 (COMx)   <- newer chipset
#   Qualcomm HS-USB Diagnostics 9025 (COMx)   <- older chipset

# ---- Find the exact Qualcomm driver via PowerShell ----
Get-PnpDevice -Class Ports | Where-Object { $_.FriendlyName -like "*Qualcomm*" }

# ---- List installed third-party drivers (audit) ----
pnputil /enum-drivers | Select-String "Qualcomm"

# ---- Remove a driver by INF name (advanced) ----
# pnputil /delete-driver oemXX.inf /uninstall /force

  8. 8. Best practices

    • ✅ Disable Driver Signature Enforcement before installing.
    • ✅ Use the newest driver package compatible with your Windows build.
    • ✅ Connect directly to rear motherboard USB ports — avoid front-panel hubs.
    • ✅ Use a quality data cable — power-only cables cause detection failures.
    • ✅ Install drivers once, then test both QDLoader and Diag ports with a real device.
    • ✅ Keep a copy of the extracted driver folder — you may need it again on a fresh Windows install.
    • ✅ If tools like QFIL don't detect the phone, first double-check that Device Manager shows the QDLoader 9008 port with no yellow warning.

Tip: after successful installation, keep the QDLoader 9008 and Diag 900E drivers readily available. If you ever reinstall Windows or move to a new PC, you can re-bind them in a few minutes using the manual method with qcser.inf.
