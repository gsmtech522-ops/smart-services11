Boot into Recovery Mode Using ADB Command

Type
Quick Guide
Level
Beginner
Time
~1 minute
Applies to
All Android devices
Last updated
YYYY-MM-DD

If your phone's Volume or Power buttons are stuck, broken, or you simply want a faster way to enter Recovery Mode, an ADB command is the cleanest solution. Boot straight into recovery in ~10 seconds — no button mashing needed.

Reference

  1. 1. Prerequisites

    1. ADB & Fastboot installed — see setup guide.
    2. USB Debugging enabled (Settings → Developer Options).
    3. Phone connected to the PC and "Allow USB Debugging" prompt accepted.

  2. 2. Steps

    1. Open PowerShell or CMD in your Platform Tools folder.
    2. Verify the connection:
    adb devices

    You should see the device serial number listed.

    1. Send the reboot-to-recovery command:
    adb reboot recovery

    The phone instantly reboots into Recovery Mode (Stock or Custom like TWRP/OrangeFox).

  3. 3. Troubleshooting

    ProblemFix
    Phone reboots normally instead of recoverySome OEMs override the recovery target. Hold Volume Up while the phone restarts.
    adb: device unauthorizedAccept the USB debugging prompt.
    adb: no devices foundWrong cable or missing drivers — try a different USB 2.0 port.
