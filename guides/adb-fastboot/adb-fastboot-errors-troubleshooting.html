The most common ADB and Fastboot errors, why they happen, and exactly how to fix them.

Reference

  1. 1. adb devices shows "unauthorized"

    Why it happens: your PC is trying to talk to the phone, but you haven't granted the security permission on the phone screen itself.

    Fix:

    1. Disconnect the USB cable.
    2. Go to Settings → Developer Options on the phone.
    3. Tap Revoke USB debugging authorizations → OK.
    4. Reconnect the USB cable.
    5. Watch the phone screen for "Allow USB debugging?".
    6. Check Always allow from this computer and tap Allow.
    7. Run adb devices again — status changes from unauthorized to device.

  2. 2. 'adb' (or 'fastboot') is not recognized

    Why it happens: Windows doesn't know where adb.exe or fastboot.exe is located — the environment variable is missing, or the tool wasn't installed system-wide.

    Quick fix:

    • Always run your ADB installer as Administrator and press Y when asked to install system-wide.

    Manual fix:

    1. Locate your ADB folder (usually C:\adb or C:\platform-tools).
    2. Copy the folder path.
    3. This PC → Properties → Advanced System Settings → Environment Variables.
    4. Under System Variables, select Path → Edit.
    5. Click New, paste the path, OK all windows.
    6. Restart Command Prompt.

  3. 3. < waiting for device > in Fastboot

    Why it happens: Fastboot is waiting for the phone to be recognized in bootloader mode, but the bootloader USB driver is missing or incorrect.

    Fix:

    1. Keep the phone connected in Fastboot mode and open Device Manager.
    2. Look for Android under Other Devices with a yellow warning.
    3. Right-click → Update driver → Browse → Let me pick from a list…
    4. Select Android Device → choose Android Bootloader Interface → Next.
    5. The moment the driver installs, the command finishes in the terminal.

  4. 4. cannot load 'filename.img': No such file or directory

    Why it happens: CMD cannot find the image file — it's not in the current folder.

    Fix:

    • Method 1: Move the image file into the same folder as your CMD (usually C:\adb or C:\platform-tools).
    • Method 2 (easiest): instead of typing the file name, type the command (e.g. fastboot flash recovery), then drag and drop the file from desktop into the CMD window — Windows pastes the full path.

  5. 5. Command not allowed / Flashing is not allowed for Lock State

    Why it happens: you're attempting to flash critical partitions while the bootloader is still locked.

    Fix:

    • Unlock the bootloader first:
    fastboot oem unlock
# or on newer devices:
fastboot flashing unlock
    • For brands like Xiaomi, Huawei or Vivo, you must use the official brand-specific unlock tool first.
    • Ensure OEM Unlocking is enabled in Developer Options on the phone.

  6. 6. protocol fault (no status)

    Why it happens: the data connection between phone and PC got cut mid-process — usually a physical (cable/port) issue.

    Fix:

    • Use a high-quality original USB data cable.
    • Use a USB 2.0 port (black) instead of USB 3.0 (blue).
    • If only USB 3 ports are available, insert a USB 2.0 hub in between.
    • Or run this as Administrator in CMD to force compatibility:
    reg add "HKLM\SYSTEM\CurrentControlSet\Control\usbflags\18D1D00D0100" /v "osvc" /t REG_BINARY /d "0000" /f
