How to Setup ADB & Fastboot on Windows PC

Type
Step-by-Step Guide
Level
Beginner
Time
~10 minutes
Applies to
Windows 10 and Windows 11
Last updated
YYYY-MM-DD

Whether you want to service Android firmware, unlock a bootloader, flash a custom recovery, or run terminal commands on your Android device, having ADB (Android Debug Bridge) and Fastboot configured on your PC is essential.

While setting up the official Android SDK Platform Tools can feel overwhelming for beginners, the methods below make the entire process fast and simple. This guide walks you through both automated and manual methods on Windows.

Reference

  1. 1. Prerequisites

    Before starting, make sure you have:

    • USB Debugging enabled on your Android phone (Settings → About phone → tap Build number 7 times → Developer options → USB debugging).
    • Google USB Driver — download from the official Android Developers site.
    • SDK Platform Tools — download from the official Platform Tools page.
    • A working USB data cable (not a charge-only cable).

    Tip: Use a USB 2.0 port if your phone does not appear in adb devices — USB 3.x can occasionally cause detection issues on older PCs.

  2. 2. Method 1 — Automatic installation (easiest)

    The automated installer configures ADB, Fastboot and system-wide drivers in under a minute.

    1. Download the 15-Second ADB Installer from the link in Method 3 below.
    2. Extract the .zip or .rar file to a folder.
    3. Right-click adb-setup.exe and select Run as Administrator.
    4. Answer Y (yes) to all three prompts: install ADB and Fastboot, install system-wide, and install device drivers.
    5. Complete the driver installation wizard — click Next, then Install, then Finish.
    6. Close and reopen the terminal before testing.

    Only download from trusted sources. Random "ADB installer" files from unofficial sites can contain malware. Prefer Method 2 (official Google Platform Tools) when you are unsure.

  3. 3. Method 2 — Manual install via official Platform Tools (recommended)

    This is the safest and most up-to-date method. You are downloading directly from Google — no third-party installers involved.

    Step 1 — Download Google USB Driver. From the official Android Developers site. Extract the zip file.

    Step 2 — Download Platform Tools. From the official Platform Tools page. Extract the zip to a permanent location — for example:

    C:\platform-tools\

    Inside that folder you should see adb.exe, fastboot.exe, and AdbWinApi.dll.

    Step 3 — Install ADB drivers manually.

    1. Open Device Manager (press Win + X → Device Manager).
    2. Connect your phone to the PC with a USB cable.
    3. Under Other devices, find Android ADB Interface or Unknown device.
    4. Right-click it and choose Update driver.
    5. Select Browse my computer for drivers.
    6. Choose Let me pick from a list of available drivers on my computer → Next.
    7. Click Have Disk… → Browse… and navigate to your extracted Google USB Driver folder.
    8. Select android_winusb.inf → Open → OK.
    9. Select Android ADB Interface from the list → Next to finish installation.

    Windows 11 note: if the driver is blocked by signature enforcement, temporarily disable it from Advanced Startup → Troubleshoot → Advanced options → Startup Settings, install the driver, then re-enable.

  4. 4. Verify ADB & Fastboot detection

    Once the drivers are installed, confirm that your computer communicates with your phone.

    Testing ADB mode:

    1. Open your extracted platform-tools folder.
    2. Hold Shift and right-click anywhere in the folder's empty space → Open PowerShell window here (or Open Terminal here).
    3. Connect your phone via USB and unlock its screen.
    4. Run the command:
    .\adb devices
    # Command Prompt (not PowerShell)
adb devices
    1. A prompt will appear on your phone: "Allow USB debugging?" — tick Always allow from this computer and tap Allow.
    2. Run adb devices again. You should see your device's serial number followed by the word device:
    List of devices attached
R58M123ABCD     device

    If you see "unauthorized": unlock the phone and accept the prompt again. If you see "offline", unplug and replug the USB cable, then run adb kill-server followed by adb start-server.

    Testing Fastboot (bootloader) mode:

    1. Reboot the phone into Fastboot directly from the terminal:
    adb reboot bootloader
    1. Your phone restarts into a screen showing FASTBOOT or BOOTLOADER.
    2. In your PC terminal, confirm the connection:
    fastboot devices
    1. You should see your device's serial number listed. Return the phone to normal mode:
    fastboot reboot

  5. 5. Method 3 — 15-Second ADB Installer (fastest)

    The quickest path if you trust the source and want everything done in one shot.

    1. Download & extract the 15-Second ADB Installer package (.zip or .rar).
    2. Run as Administrator: right-click adb-setup.exe → Run as Administrator. This is needed to copy files into your system directory.
    3. Configure installation: a blue Command Prompt window appears with three questions — answer Y to all:
      • Install ADB and Fastboot? → Y
      • Install ADB system-wide? → Y (lets you run ADB from any folder)
      • Install device drivers? → Y
    4. Complete driver setup: in the Device Driver Installation Wizard, click Next.
    5. If a Windows Security prompt appears, click Install this driver software anyway.
    6. Click Finish. Open a new terminal and run adb devices to confirm.

    Source safety: only download the installer from trusted mirrors (e.g. SourceForge: QuickADB). Avoid unknown blogs and file-sharing links.

  6. 6. Add Platform Tools to PATH (optional but useful)

    If you want to run adb and fastboot from any folder — not just the platform-tools folder — add it to PATH:

    1. Press Win, type env, and select Edit the system environment variables.
    2. Click Environment Variables…
    3. Under User variables, select Path → Edit.
    4. Click New and paste your platform-tools path:
    C:\platform-tools
    1. Click OK on all windows. Open a new terminal and run adb version from any folder to confirm.

  7. 7. Troubleshooting

    ProblemFix
    adb is not recognizedRun it from inside the platform-tools folder with .\adb, or add the folder to PATH.
    Device shows unauthorizedUnlock the phone and tap Allow on the USB debugging prompt.
    Device shows offlineRun adb kill-server then adb start-server, and replug the cable.
    adb devices is emptyTry a different USB cable and USB 2.0 port. Check Device Manager for "Unknown device".
    Fastboot not detectingReinstall Google USB Driver; on Windows 11, disable driver signature enforcement temporarily.
    Driver install blockedRun the installer as Administrator; temporarily disable antivirus.
    Multiple phones connectedSpecify serial: adb -s <serial> shell

  8. 8. Complete command reference

    # ---- ADB basics ----
adb version                     # show installed version
adb devices                     # list connected devices
adb start-server                # start ADB daemon
adb kill-server                 # stop ADB daemon

# ---- ADB file transfer ----
adb push file.txt /sdcard/      # PC → phone
adb pull /sdcard/file.txt .     # phone → PC

# ---- ADB device control ----
adb reboot                      # normal reboot
adb reboot bootloader           # into Fastboot
adb reboot recovery             # into Recovery

# ---- ADB shell ----
adb shell                       # open a shell on the phone
adb shell pm list packages      # list installed packages
adb shell dumpsys battery       # battery info

# ---- Sideload OTA ----
adb sideload update.zip

# ---- Fastboot ----
fastboot devices                # list devices in Fastboot
fastboot reboot                 # reboot to system
fastboot flashing unlock        # unlock bootloader (supported devices)
fastboot flash boot boot.img    # flash a boot image
fastboot flash recovery rec.img # flash a recovery image
fastboot oem device-info        # device info (some OEMs)
fastboot getvar all             # dump all bootloader variables

# ---- Fix common issues ----
adb kill-server && adb start-server
adb -s <serial> shell            # target a specific device

  9. 9. Safety & legal notes

    • ✅ Only use ADB and Fastboot on your own devices, or devices you are authorized to service.
    • ✅ Back up your data and IMEI before flashing anything.
    • ⚠️ fastboot flashing unlock wipes all data on most phones — this is intentional.
    • ⚠️ Flashing the wrong image can brick the phone — always download firmware matching your exact model and region.
    • 🚫 Do not bypass another person's phone lock, FRP, or account — it is illegal in most countries.

  10. 10. Conclusion

    Your Windows PC is now fully configured with ADB and Fastboot. You can safely run terminal commands, debug software issues, or communicate with Android servicing tools — from any folder if you set up PATH.
