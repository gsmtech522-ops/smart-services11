Backup & Restore APK + App Data Using ADB

Type
Step-by-Step Guide
Level
Beginner
Time
~5 minutes
Applies to
All Android devices
Last updated
YYYY-MM-DD

When upgrading your phone, performing a factory reset or preparing a device for a software flash, keeping your apps and their data safe is a top priority. With ADB you can create a complete, secure backup of your apps and data — no root required.

Reference

  1. 1. Prerequisites

    • ADB & Fastboot installed — see setup guide.
    • USB Debugging enabled (Settings → Developer Options → USB Debugging).
    • Phone connected to the PC with the "Allow USB Debugging" prompt accepted.
    • You must know the target app's package name (e.g. com.whatsapp).

  2. 2. Backup commands

    Open PowerShell in your Platform Tools folder and verify the connection:

    adb devices

    Option A — Backup a specific app and its data (recommended):

    adb backup -f my_app_backup.ab -apk com.whatsapp

    This creates my_app_backup.ab on your PC.

    Option B — Backup all installed apps and their data:

    adb backup -f all_apps_backup.ab -apk -all

    Option C — Backup app data only (skip the APK):

    adb backup -f my_app_data.ab -noapk com.whatsapp

  3. 3. Restore the backup

    To restore in the future:

    adb restore my_app_backup.ab

    The phone will prompt you to confirm the restore.

  4. 4. Notes & limitations

    • Deprecated in Android 12+ — adb backup may be blocked or partially work on newer Android versions.
    • Some apps (with backup disabled in their manifest) cannot be backed up via ADB.
    • Google account, passwords and encrypted data are not included.
    • Use this for local, offline backups — not as a replacement for Google cloud backup.
