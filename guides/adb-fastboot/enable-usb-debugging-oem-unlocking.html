Enable USB Debugging & OEM Unlocking on Android Phone

Type
Step-by-Step Guide
Level
Beginner
Time
~3 minutes
Applies to
Android 8 – 15 (Samsung, Xiaomi, Realme, Oppo, Vivo, Infinix, Tecno, Google Pixel)
Last updated
YYYY-MM-DD

Before connecting your Android device to a PC for ADB / Fastboot operations, firmware flashing, or driver setup, you must enable USB Debugging and OEM Unlocking from Developer Options. Without these two settings, ADB will not detect your phone, and Fastboot commands like flashing unlock will be rejected.

Reference

  1. 1. Overview — what each setting does

    SettingPurposeRequired for
    Developer Options Hidden menu where advanced settings live Enabling USB Debugging and OEM Unlocking
    USB Debugging Allows ADB commands over USB ADB, sideload, logcat, file transfer, service tools
    OEM Unlocking Allows the bootloader to be unlocked Fastboot unlock, custom recovery, custom ROM

    Important: OEM Unlocking may be greyed out on some phones (especially carrier-locked Samsung and Xiaomi devices still inside their waiting period). If it is disabled, wait the required time or check with the manufacturer.

  2. 2. Step-by-step: enable Developer Options

    1. Open Settings on your Android phone.
    2. Go to About Phone.
    3. Locate the Build Number entry.
      • Samsung: Settings → About phone → Software information → Build number
      • Xiaomi / Redmi / POCO: Settings → About phone → MIUI / HyperOS version
      • Realme / Oppo: Settings → About device → Version
      • Vivo: Settings → System management → About phone → Software version
      • Google Pixel / stock Android: Settings → About phone → Build number
    4. Tap Build Number 7 times in a row.
    5. After the first few taps, a countdown appears: "You are now 3 steps away from being a developer".
    6. When you have tapped 7 times, you will see: "You are now a developer!"

  3. 3. Step-by-step: open Developer Options

    1. Go back to the main Settings menu.
    2. Find Developer Options — its location differs per brand:
      • Samsung: Settings → Developer options (at the bottom)
      • Xiaomi / Redmi / POCO: Settings → Additional settings → Developer options
      • Realme / Oppo: Settings → Additional settings → Developer options
      • Vivo: Settings → System management → Developer options
      • Pixel / stock Android: Settings → System → Developer options
    3. Open it. You will see a long list of advanced settings.

  4. 4. Step-by-step: enable USB Debugging and OEM Unlocking

    1. Inside Developer Options, scroll down and toggle USB Debugging to ON.
    2. Toggle OEM Unlocking to ON as well.
    3. Read the confirmation dialogs (especially for OEM Unlocking, since unlocking the bootloader wipes all data).
    4. Tap Enable or OK on both dialogs.

    OEM Unlocking warning: turning this on allows the bootloader to be unlocked. Unlocking the bootloader wipes all data on most phones and may void warranty. Only do this on a device you own and are prepared to reset.

  5. 5. Verify the settings are active

    Confirm that USB Debugging is actually working by connecting the phone to a PC:

    1. Connect the phone to the PC via a data USB cable.
    2. Open Device Manager (Win + X → Device Manager).
    3. Look under Universal Serial Bus devices or Android Device. You should see Android ADB Interface (or your phone's model name) with no warning icon.
    4. Open a terminal in your platform-tools folder and run:
    adb devices

    The first time, the phone will show a prompt: "Allow USB debugging?" — tick Always allow from this computer and tap Allow.

    Run the command again. You should see your device listed with the word device:

    List of devices attached
R58M123ABCD     device

  6. 6. Driver verification & setup

    When you connect your phone to the PC, open Device Manager (Win + X → Device Manager).

    If you see Android ADB Interface (or Unknown device) with a yellow warning triangle under Other devices, the proper drivers are not installed yet.

    To fix this, install the official ADB and Fastboot drivers:

    👉 How to Setup ADB and Fastboot on Windows PC — complete step-by-step guide with automatic installer and manual Google Platform Tools methods.

  7. 7. Troubleshooting

    ProblemFix
    OEM Unlocking option is greyed out Carrier-locked phones or Xiaomi waiting period. Wait 7–168 hours depending on brand, or contact the carrier.
    Developer Options not appearing Tap Build Number 7 times again — some brands require extra taps. Check you tapped the right Build Number (not Android version).
    USB Debugging won't stay on Turn off "Verify apps over USB" in Developer Options, or reboot and re-enable.
    "adb: device unauthorized" Unlock the phone and tap Allow on the USB debugging prompt. If no prompt appears, run adb kill-server then adb start-server.
    "adb: no devices found" Wrong cable (charge-only), wrong USB port, or missing drivers. Try a different cable and USB 2.0 port.
    Phone does not appear in Device Manager Install Google USB Drivers — see the ADB & Fastboot setup guide linked above.
    Warning icon persists after driver install Uninstall the device in Device Manager, replug, and let Windows reinstall. Or disable driver signature enforcement on Windows 11.

  8. 8. Safety & legal notes

    • ✅ USB Debugging and OEM Unlocking are safe to enable — they don't change anything by themselves.
    • ✅ You can turn them off again at any time from Developer Options.
    • ⚠️ OEM Unlocking + Fastboot unlock wipes all data. Back up first.
    • ⚠️ Unlocking the bootloader voids warranty on most phones and may trigger Knox (Samsung) or SafetyNet/Play Integrity warnings.
    • 🚫 Never enable these settings on someone else's phone without permission — it is a legal and privacy violation.
    • 🚫 Do not use USB Debugging to bypass another person's lock screen, FRP, or Google account. Illegal in most countries.

  9. 9. What's next?

    Once USB Debugging and OEM Unlocking are on, you can:

    • Install and verify ADB & Fastboot on Windows
    • Run adb devices and confirm the connection
    • Unlock the bootloader with fastboot flashing unlock (supported devices)
    • Flash stock firmware to unbrick a phone
    • Explore chipset-specific tools: MediaTek, Qualcomm, SPD

  10. 10. Quick reference — commands after enabling

    # ---- Confirm ADB sees the phone ----
adb devices

# ---- Reboot into Fastboot / Bootloader ----
adb reboot bootloader

# ---- Confirm Fastboot sees the phone ----
fastboot devices

# ---- Unlock bootloader (supported devices, wipes data) ----
fastboot flashing unlock

# ---- Return to normal system ----
fastboot reboot
