Take Screenshots & Screen Recordings via ADB

Type
Step-by-Step Guide
Level
Beginner
Time
~3 minutes
Applies to
All Android devices
Last updated
YYYY-MM-DD

Capturing screenshots and recordings via ADB is invaluable for techs who need to document issues, record bootloops, or operate broken-button phones. Frames are piped directly over USB — nothing is stored on the phone.

Reference

  1. 1. Prerequisites

    • ADB & Fastboot installed.
    • USB Debugging enabled.
    • Device connected and authorized via adb devices.

  2. 2. Screenshots — Method 1 (two-step)

    adb shell screencap -p /sdcard/screenshot.png
adb pull /sdcard/screenshot.png .
adb shell rm /sdcard/screenshot.png

  3. 3. Screenshots — Method 2 (one-line direct pipe)

    Windows CMD:

    adb shell exec-out screencap -p > screenshot.png

    PowerShell:

    adb shell "screencap -p" | Out-File -Encoding ascii screenshot.png

  4. 4. Screen recording

    Basic recording:

    adb shell screenrecord /sdcard/demo.mp4

    Press Ctrl+C in the terminal to stop.

    Custom bitrate, resolution and time limit:

    # 8 Mbps bitrate
adb shell screenrecord --bit-rate 8000000 /sdcard/high_quality.mp4

# 720p resolution
adb shell screenrecord --size 1280x720 /sdcard/720p_rec.mp4

# 60-second limit
adb shell screenrecord --time-limit 60 /sdcard/1min_clip.mp4

    Pull and cleanup:

    adb pull /sdcard/demo.mp4 .
adb shell rm /sdcard/demo.mp4

  5. 5. Real-time screen mirroring (scrcpy)

    To view and control the phone screen in real-time without saving video files, use open-source scrcpy:

    scrcpy --max-fps 60 --bit-rate 10M

    A low-latency window of the phone's screen opens instantly.

  6. 6. Limitations

    • Blank / black video output: DRM-protected screens (banking apps, password fields) block frame capture.
    • Recording stops at 3 minutes: Android's built-in screenrecord enforces a 180-second hard limit. For longer sessions, use scrcpy --record long_capture.mp4.
