Capture Logcat & Kernel Logs via ADB

Type
Step-by-Step Guide
Level
Intermediate
Time
~5 minutes
Applies to
All Android devices
Last updated
YYYY-MM-DD

When an Android app crashes, a framework service fails, or the device hits a kernel panic, visual diagnostics are not enough. Capturing real-time Logcat and kernel dmesg logs gives you stack traces, error codes and driver events to find the exact root cause.

Reference

  1. 1. Prerequisites

    • ADB & Fastboot installed.
    • USB Debugging enabled.
    • Phone connected and authorized via adb devices.

  2. 2. Part 1 — Android system logs (Logcat)

    Stream live:

    adb logcat

    Press Ctrl+C to stop.

    Dump to a text file:

    adb logcat -d > logcat_dump.txt

    The -d flag dumps the current buffer and exits.

    Clear the buffer before reproducing a bug:

    adb logcat -c
adb logcat -d > fresh_crash_log.txt

    Filter by severity (V/D/I/W/E/F):

    adb logcat *:E > errors_only.txt

# Filter by specific app tag
adb logcat -s ActivityManager:I AndroidRuntime:E

  3. 3. Part 2 — Specific buffer dumps

    # Radio / SIM / network
adb logcat -b radio -d > radio_network.txt

# System events
adb logcat -b events -d > system_events.txt

# Combined buffers
adb logcat -b main -b system -b crash -d > full_system.txt

  4. 4. Part 3 — Low-level kernel logs

    Use this for driver failures, sudden reboots, Wi-Fi/Bluetooth chip crashes or mount errors.

    Live kernel ring buffer:

    adb shell dmesg > kernel_log.txt

    Panic logs after a crash or random reboot (Android 10 and older):

    adb shell cat /proc/last_kmsg > last_kernel_crash.txt

    Panic logs (Android 11+ with pstore):

    adb shell cat /sys/fs/pstore/console-ramoops > last_kernel_crash.txt

  5. 5. Part 4 — Full Android bug report

    Captures Logcat, dmesg, battery stats, memory, dumpsys and device state in a single zip.

    # Android 8.0 and newer
adb bugreport bugreport.zip

# Older devices (Android 7.1 and older)
adb bugreport > full_bugreport.txt

  6. 6. Troubleshooting

    Issue: dmesg: read kernel buffer failed: Permission denied

    Cause: Android restricts kernel ring buffer access on user builds without root.

    Fix — request root in the shell:

    adb shell
su
dmesg > /sdcard/kernel_log.txt

    Issue: logcat output gets truncated too quickly

    Cause: default 256 KB buffer overflows under heavy log activity.

    Fix — increase buffer to 16 MB before testing:

    adb logcat -G 16M
