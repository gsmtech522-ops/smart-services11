The complete list of useful ADB and Fastboot commands for Android flashing, bootloader unlocking, partition management and troubleshooting.

Whether you are a seasoned mobile software technician or a developer initializing your first custom ROM setup, remembering every command is impossible. This cheat sheet organizes all essential commands by function.

Reference

  1. 1. Category 1 — Basic ADB connection commands

    Commands used while the phone is powered on normally.

    CommandDescription
    adb devicesLists all connected Android devices with USB debugging authorized.
    adb start-serverStarts the ADB background process on your PC.
    adb kill-serverStops the ADB server (useful if a tool freezes or fails to detect a port).
    adb versionDisplays the version number of your installed ADB platform tools.

  2. 2. Category 2 — Reboot & boot mode commands

    CommandDescription
    adb rebootRestarts your device normally.
    adb reboot bootloader / adb reboot fastbootForces the phone to reboot into Fastboot Mode.
    adb reboot recoveryRestarts directly into Recovery Mode.
    adb reboot edlForces supported Qualcomm devices into Emergency Download Mode (9008).

  3. 3. Category 3 — File management & app installation

    CommandDescription
    adb install app_name.apkInstalls an Android application from your PC.
    adb install -r app_name.apkReinstalls or updates while keeping user data.
    adb uninstall package_nameUninstalls an app by package name (e.g. com.instagram.android).
    adb push C:\file.txt /sdcard/Copies a file from PC to the phone's internal storage.
    adb pull /sdcard/photo.jpg C:\Users\DesktopCopies a file from the phone back to your PC.

  4. 4. Category 4 — Log tracking & device info

    CommandDescription
    adb logcatDisplays live system logs (Ctrl+C to stop).
    adb logcat > c:\log.txtSaves the log output to a text file.
    adb get-serialnoDisplays the phone's unique hardware serial number.
    adb shell getprop ro.build.version.releaseShows the current Android version.

  5. 5. Category 5 — Advanced ADB shell commands

    CommandDescription
    adb shell pm list packagesLists every app package installed on the system.
    adb shell pm list packages -3Lists only third-party (user-installed) apps.
    adb shell pm uninstall -k --user 0 package_nameForcefully removes system bloatware without root.
    adb shell screencap -p /sdcard/screenshot.pngTakes a screenshot and saves it to storage.
    adb shell screenrecord /sdcard/video.mp4Records the screen to a video file.

  6. 6. Category 6 — Fastboot mode commands (bootloader)

    These commands only work when the phone is in Fastboot / Bootloader mode.

    Connection & info

    CommandDescription
    fastboot devicesLists devices recognized in Fastboot mode. If empty, check bootloader drivers.
    fastboot getvar allDumps hardware details: IMEI status, CPU type, bootloader state, baseband.

    Unlocking bootloader

    CommandDescription
    fastboot oem unlockUnlock on older or generic models.
    fastboot flashing unlockUnlock on newer devices (Android 8+).
    fastboot oem lock / fastboot flashing lockRe-lock to return to standard security.

    Flashing partitions (use with caution)

    CommandDescription
    fastboot flash recovery recovery.imgFlashes a custom recovery (TWRP / OrangeFox).
    fastboot flash boot boot.imgFlashes kernel / boot image (Magisk root).
    fastboot flash system system.imgFlashes the Android OS partition.
    fastboot boot recovery.imgTemporarily boots a recovery without flashing it.

    Wiping & resets

    CommandDescription
    fastboot erase cacheWipes the cache partition.
    fastboot format userdata / fastboot -wFull factory reset via Fastboot.

    Leaving Fastboot

    CommandDescription
    fastboot rebootExits Fastboot and restarts the device.
    fastboot reboot recoveryExits Fastboot and boots into Recovery.
