Find Installed App Package Name & UID via ADB

Type
Quick Guide
Level
Beginner
Time
~2 minutes
Applies to
All Android devices
Last updated
YYYY-MM-DD

In Android customization and troubleshooting, knowing the app's display name (like "WhatsApp") is not enough. Android identifies apps by two unique identifiers: Package Name (e.g. com.whatsapp) and UID (User ID, e.g. u0_a123). ADB is the fastest way to find both.

Reference

  1. 1. Prerequisites

    • ADB & Fastboot installed — see setup guide.
    • USB Debugging enabled — see this guide.
    • Phone connected to the PC and authorized.

  2. 2. Part 1 — Find app package names

    1. Open PowerShell in Platform Tools.
    2. Verify the connection:
    adb devices
    1. Enter the device shell:
    adb shell
    1. List apps by category:
    # All packages
pm list packages

# Third-party (user-installed) apps
pm list packages -3

# System apps
pm list packages -s

    Search for a specific app (grep):

    pm list packages | grep facebook

  3. 3. Part 2 — Find app UID

    Once you have the package name, find its UID inside adb shell:

    Method 1 — dumpsys (fastest):

    dumpsys package com.whatsapp | grep userId

    Output will show something like userId=10135 — that number is the app's UID.

    Method 2 — ps (only if the app is running):

    ps -A | grep com.whatsapp

    The first column of the output shows the UID (e.g. u0_a135).
