Change Display Resolution & DPI via ADB

Type
Step-by-Step Guide
Level
Intermediate
Time
~5 minutes
Applies to
All Android 7+ devices
Last updated
YYYY-MM-DD

Modifying resolution and DPI improves gaming performance, reduces GPU load, saves battery or fixes UI scaling on phones with replacement screens. All done via the Window Manager (wm) shell tool — no root needed.

Reference

  1. 1. Prerequisites

    • ADB & Fastboot installed.
    • USB Debugging enabled.
    • Phone connected and authorized.

  2. 2. Step 1 — Check current resolution & density

    Record your default values before changing anything.

    adb shell wm size
# Example output: Physical size: 1080x2400

adb shell wm density
# Example output: Physical density: 420

  3. 3. Step 2 — Change resolution

    Lowering resolution (e.g. 1080p → 720p) reduces GPU load for gaming.

    adb shell wm size 720x1600

    Aspect ratio: always keep the same ratio (16:9, 18:9, 20:9) — otherwise the UI stretches or leaves black bars.

  4. 4. Step 3 — Change density (DPI)

    • Lower DPI: smaller elements, more on-screen content.
    • Higher DPI: larger elements for readability.
    adb shell wm density 360

    The screen flickers briefly and refreshes with the new scaling.

  5. 5. Step 4 — Restore defaults

    adb shell wm size reset
adb shell wm density reset

  6. 6. Emergency recovery

    If the screen goes black, touch stops aligning, or System UI crashes:

    1. Keep the USB cable connected (do not disconnect).
    2. Run both reset commands immediately:
    adb shell wm size reset
adb shell wm density reset
    1. If System UI is still frozen, force-restart the graphical interface:
    adb shell stop && adb shell start

    Recommended DPI ranges:

    Resolution ClassTypical ResolutionRecommended DPI
    HD / HD+720 × 1280 / 720 × 1600280 – 320
    FHD / FHD+1080 × 1920 / 1080 × 2400380 – 440
    QHD / QHD+1440 × 2560 / 1440 × 3200510 – 560
