How to Backup Android Firmware Using ADB & Fastboot

Type
Step-by-Step Guide
Level
Advanced
Time
~20 minutes
Applies to
All Android devices (root or unlocked bootloader)
Last updated
YYYY-MM-DD

Before flashing custom ROMs, modifying system partitions or rooting, creating a full system backup is your ultimate safety net. ADB and Fastboot allow you to backup partition images directly from an active Android environment or from the bootloader.

Reference

  1. 1. Requirements

    • ADB & Fastboot setup on your PC.
    • USB Debugging enabled on the phone.
    • Unlocked bootloader (for Fastboot partition dumping).
    • Root access (for ADB dd commands while the phone is booted).

  2. 2. Method 1 — Backup individual partitions via ADB (root required)

    With Magisk or KernelSU root, ADB lets you dump raw partition images with the dd command.

    Step 1 — Connect and open ADB shell:

    adb devices
adb shell su

    Grant superuser permission on the phone when prompted.

    Step 2 — Locate partition memory blocks:

    ls -l /dev/block/by-name/

    This shows all system partitions and their block locations (e.g. boot → /dev/block/mmcblk0p21).

    Step 3 — Dump critical partitions to /sdcard/:

    # Boot partition (kernel + ramdisk)
dd if=/dev/block/by-name/boot of=/sdcard/boot.img

# Recovery partition
dd if=/dev/block/by-name/recovery of=/sdcard/recovery.img

# VBMeta (verified boot)
dd if=/dev/block/by-name/vbmeta of=/sdcard/vbmeta.img

# Modem / NVRAM (IMEI + network)
dd if=/dev/block/by-name/modem of=/sdcard/modem.img

    Step 4 — Pull the images to your PC:

    exit
exit
adb pull /sdcard/boot.img C:\Android_Backup\boot.img
adb pull /sdcard/recovery.img C:\Android_Backup\recovery.img
adb pull /sdcard/vbmeta.img C:\Android_Backup\vbmeta.img

  3. 3. Method 2 — Full system backup via adb backup (no root)

    If the phone is not rooted, use the legacy ADB backup bridge for user apps and system data.

    1. Connect the phone with USB Debugging on.
    2. Run:
    adb backup -apk -shared -all -f C:\Android_Backup\full_backup.ab
    1. On the phone, tap Back up my data.
    2. To restore later:
    adb restore C:\Android_Backup\full_backup.ab

    Note: adb backup is deprecated in Android 12+ — it may not work on newer OS versions.

  4. 4. Method 3 — Dump partitions in Fastboot mode

    If your device supports raw fastboot fetch (some OEMs and custom fastboot protocols), you can dump without root.

    Step 1 — Reboot into Fastboot:

    adb reboot bootloader
fastboot devices

    Step 2 — Fetch partition images:

    fastboot fetch boot boot.img
fastboot fetch recovery recovery.img
fastboot fetch vbmeta vbmeta.img

  5. 5. Important tips & warnings

    • Check storage: system and super partitions can be 4–10 GB+. Ensure free space before running dd.
    • Dynamic partitions (Android 10+): individual system files sit inside super.img — dumping it requires significant space.
    • Save IMEI safely: always back up nvram, nvdata, modem and persist images to a secure cloud or external drive.
