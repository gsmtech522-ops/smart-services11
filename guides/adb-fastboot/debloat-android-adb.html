Debloat Android & Remove System Apps via ADB (No Root)

Type
Step-by-Step Guide
Level
Intermediate
Time
~10 minutes
Applies to
All Android devices
Last updated
YYYY-MM-DD

Many phones come with unwanted manufacturer apps, carrier bloatware and heavy background services. Android doesn't allow uninstalling these from settings without root — but you can safely disable and remove them for user 0 using ADB.

Reference

  1. 1. Prerequisites

    • ADB & Fastboot installed.
    • USB cable + USB Debugging enabled.

  2. 2. Step 1 — Connect and authorize

    adb devices

    Accept Allow USB debugging on the phone if prompted.

  3. 3. Step 2 — Find the target package name

    1. Open the ADB shell:
    adb shell
    1. List packages or filter by brand:
    pm list packages
pm list packages | grep 'facebook'
pm list packages | grep 'samsung'
pm list packages | grep 'google'

  4. 4. Step 3 — Uninstall bloatware

    pm uninstall -k --user 0 com.package.name

# Example: remove Facebook installer bloat
pm uninstall -k --user 0 com.facebook.system

    Output should be: Success.

    The -k flag keeps user data and cache directories intact for easy restoration.

  5. 5. Step 4 — Alternative: disable instead of uninstall

    pm disable-user --user 0 com.package.name

  6. 6. Restore accidentally removed apps

    The APK binary is still stored in the read-only system partition — restore any time:

    cmd package install-existing com.package.name

  7. 7. Safety warnings

    • Never remove core framework apps: com.android.systemui, com.android.phone, or the vendor launcher (unless you have an alternative launcher installed).
    • Test incrementally: remove 2–3 apps at a time and check phone behavior before continuing.
    • Keep a list of what you uninstall so you can restore if a system function breaks.
