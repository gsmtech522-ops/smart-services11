How to Find Android USB Vendor ID (VID) & Product ID (PID)

Type
Reference Guide
Level
Beginner
Time
~5 minutes
Applies to
All Android devices (BROM / EDL / ADB / Fastboot)
Last updated
YYYY-MM-DD

When connecting phones in special servicing modes like EDL (Emergency Download), BROM (Boot ROM), Fastboot, or ADB, an unconfigured system may show the phone as an "Unknown USB Device" in Device Manager. Every hardware manufacturer embeds a unique hexadecimal ID into the phone's USB controller chip. By reading the VID and PID, you can determine the exact chipset and locate the required driver package.

Reference

  1. 1. Understanding USB VID & PID

    IdentifierMeaningExamples
    VID (Vendor ID) 4-digit hex code assigned to hardware manufacturers Google: 18D1 · Samsung: 04E8 · MediaTek: 0E8D · Qualcomm: 05C6
    PID (Product ID) 4-digit hex code assigned by the manufacturer to a specific hardware mode MTP mode vs. Fastboot vs. EDL mode

    Windows matches these VID / PID entries against .inf setup files to bind the appropriate driver to the USB port.

  2. 2. Method 1 — Windows Device Manager (built-in)

    The standard manual method to identify unidentified devices on any system.

    1. Right-click Start → Device Manager.
    2. Connect the phone in the target mode (key combo for EDL/BROM or Fastboot).
    3. Look under Other devices or Universal Serial Bus controllers for an entry with a yellow warning triangle.
    4. Right-click the device → Properties.
    5. Go to the Details tab.
    6. In the Property dropdown, select Hardware Ids.
    7. Examine the value string — e.g.:
    USB\VID_05C6&PID_9008&REV_0000
    • 4 chars after VID_ = Vendor ID (e.g. 05C6 → Qualcomm)
    • 4 chars after PID_ = Product ID (e.g. 9008 → EDL Emergency Mode)

  3. 3. Method 2 — USBDeview utility (automated)

    If the device connects and disconnects quickly (e.g. MediaTek BROM mode), USBDeview logs connections in real-time.

    1. Launch USBDeview as Administrator.
    2. The tool lists all USB device configurations stored in the Windows Registry.
    3. Sort by clicking the Last Plug/Unplug Date column header — recent connections rise to the top.
    4. Look for columns labeled Vendor ID and Product ID.
    5. Values appear as clean hex tokens (e.g. Vendor ID: 0e8d, Product ID: 0003 → MediaTek USB Port). Double-click the row to copy.

  4. 4. Method 3 — Fastboot terminal query

    If the device communicates in bootloader mode, query hardware registers directly via terminal:

    1. Boot into Fastboot mode and connect to the PC.
    2. Open CMD inside platform-tools.
    3. Run:
    fastboot getvar all

    Review the output for variables describing controller hardware IDs and chipset revisions.

  5. 5. Common hardware ID quick reference

    Chipset / VendorVendor ID (VID)Common Modes / PIDs
    MediaTek (MTK) 0E8D 0003 (BROM / Preloader)
    Qualcomm 05C6 9008 (EDL Mode)
    Samsung 04E8 6860 (MTP / ADB) · 685D (Odin Mode)
    Google / Generic Android 18D1 4EE0 (Fastboot Mode)

  6. 6. Troubleshooting hardware IDs

    VID_0000 & PID_0000 shown: if the Hardware ID reads VID_0000&PID_0000, it means hardware communication failed. Common causes:

    • Damaged USB data pins inside the device charging port
    • A power-only USB cable (charge-only, no data wires)
    • Insufficient USB power delivery on the motherboard

    Fix: use a high-quality data cable connected directly to the rear motherboard USB ports (avoid front-panel USB hubs).
