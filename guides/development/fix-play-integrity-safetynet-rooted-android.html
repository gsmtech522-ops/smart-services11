Fix Play Integrity & SafetyNet on Rooted Android

Type
Advanced Guide
Level
Advanced
Time
~15 minutes
Applies to
Magisk, KernelSU, KernelSU-Next, APatch (Android 8–16)
Last updated
YYYY-MM-DD

Important: SafetyNet is deprecated — Google replaced it with the Play Integrity API [citation:5]. This guide focuses on Play Integrity. Rooting weakens security; only proceed on your own device and accept the trade-offs.

When you root or install a custom ROM, Google Play Integrity checks fail — banking apps, Google Wallet, and some games stop working. The fix requires two components: spoofing device identity (Play Integrity Fix/Fork) and spoofing hardware attestation (Tricky Store + keybox). This guide covers both, plus troubleshooting.

Reference

  1. 1. Understand the verdicts

    VerdictMeaningRequired by
    MEETS_BASIC_INTEGRITYDevice passes basic checkMost apps
    MEETS_DEVICE_INTEGRITYDevice is certified (locked bootloader check)Google Play certification, Wallet, RCS
    MEETS_STRONG_INTEGRITYHardware-backed attestation (TEE)Only high-security apps (rarely needed)

    Real-world advice: most apps work with BASIC + DEVICE only. STRONG is rarely needed and requires a valid unrevoked keybox, which is hard to obtain and often revoked quickly [citation:5]. Do not chase STRONG unless an app explicitly demands it.

  2. 2. Prerequisites

    • Root manager: Magisk (with Zygisk), KernelSU (with ZygiskNext), or APatch (with ZygiskNext).
    • Zygisk enabled — required for the fix modules to inject into Google Play Services [citation:5].
    • DenyList configured in your root manager (if using Enforce DenyList).
    • Play Integrity Checker app (from Play Store) to test verdicts.

    Critical: do NOT put Google Play Services (com.google.android.gms) on the DenyList when using Play Integrity Fix — it interferes with injection [citation:4].

  3. 3. Step 1 — Install Play Integrity Fix (PIF)

    The original PIF by chiteroman was removed from GitHub. Use one of the actively maintained forks:

    ModuleDeveloperNotes
    PlayIntegrityForkosm0sisActively maintained, supports custom fields [citation:2]
    PlayIntegrityFix InjectKOWX712Preserved continuation of chiteroman's PIF [citation:10]
    PlayIntegritySuperForkfrpunlocking-comFork with autopif2 [citation:4]

    Installation:

    1. Download the latest .zip from the fork's GitHub releases.
    2. Open your root manager → Modules → Install from storage.
    3. Select the ZIP and flash.
    4. Reboot.

  4. 4. Step 2 — Install Tricky Store (for DEVICE integrity)

    Tricky Store spoofs the hardware keystore attestation — required for MEETS_DEVICE_INTEGRITY on Android 13+ [citation:6].

    1. Download Tricky Store from its XDA thread or GitHub.
    2. Flash it via your root manager.
    3. Reboot.
    4. Configure target.txt to include:
      • com.google.android.gms
      • com.android.vending

    Keybox: Tricky Store needs a keybox.xml to spoof hardware attestation. Without a valid keybox, you can only pass BASIC (not DEVICE) [citation:5]. Some all-in-one modules (e.g. PlayIntegrity-TrickyStore-AIO.zip) bundle a keybox [citation:6], but these are often revoked quickly.

  5. 5. Step 3 — Configure DenyList & root hiding

    1. Open your root manager's settings.
    2. Enable Zygisk (Magisk) or install ZygiskNext (KernelSU/APatch).
    3. Enable Enforce DenyList.
    4. Add these to the DenyList:
      • Your banking apps
      • Google Wallet / Google Pay
      • Any app that detects root
    5. Do NOT add Google Play Services — it breaks PIF [citation:4].
    6. Reboot.

  6. 6. Step 4 — Test the verdicts

    1. Install the Play Integrity API Checker app from Play Store.
    2. Run the check.
    3. Expected results:
      • MEETS_BASIC_INTEGRITY ✅
      • MEETS_DEVICE_INTEGRITY ✅ (with valid keybox + Tricky Store)
      • MEETS_STRONG_INTEGRITY ⚠️ (only with unrevoked keybox)

  7. 7. Troubleshooting — common failures

    Failing BASIC integrity:

    • Your setup is fundamentally wrong. Disable all modules except PIF and retry [citation:4].
    • Try a different custom.pif.json (fingerprint).
    • Xposed/LSPosed modules that hook GMS can trigger detection [citation:4].

    Failing DEVICE integrity:

    • KernelSU/APatch: disable Zygisk Next → reboot → re-enable Zygisk Next → reboot [citation:4].
    • Custom kernel: check if your kernel name is on the banned list. Run adb shell uname -r [citation:5].
    • Custom ROM: your ROM may be signed with the AOSP testkey. Check: adb shell unzip -l /system/etc/security/otacerts.zip [citation:4].
    • Keybox revoked: if you were passing DEVICE and suddenly only pass BASIC, your keybox was revoked. Find a new one or accept BASIC only [citation:5].

    Play Store shows "Device is not certified":

    • Reflash PIF module.
    • Clear Google Play Store cache/data (com.android.vending).
    • Clear Google Play Services cache/data (com.google.android.gms) — this may require re-pairing WearOS devices [citation:2].

    Google Wallet / Tap to Pay fails:

    • Ensure you pass DEVICE integrity (Wallet checks it internally even on Android 13+) [citation:2].
    • Clear Google Wallet cache.
    • Clear Google Play Services data and wait 24–72 hours for it to settle [citation:2].

    RCS (Google Messages) fails:

    • Clear Google Messages cache/data [citation:2].
    • Ensure DEVICE integrity passes.

  8. 8. Reading module logs

    If PIF is installed but not working, check its logs:

    adb shell "logcat | grep 'PIF/'"
# or if rooted:
su -c "logcat | grep 'PIF/'"

    To increase log verbosity, edit custom.pif.prop and set verboseLogs=100 [citation:2].

  9. 9. Alternative — All-in-one modules

    If manual setup is frustrating, some modules bundle PIF + Tricky Store + keybox:

    • PlayIntegrity-TrickyStore-AIO.zip — combines PIF Fork v18 and Tricky Store with a pre-installed keybox [citation:6].
    • JerryManager — KernelSU/APatch module with Web UI for root hiding and integrity [citation:3].

    Risk: bundled keyboxes are often revoked quickly. These modules are convenient but may stop working without notice.

  11. 11. Best practices

    • ✅ Use PlayIntegrityFork (osm0sis) — most actively maintained [citation:2].
    • ✅ Enable Zygisk and configure DenyList properly.
    • ✅ Test with Play Integrity Checker after every change.
    • ✅ Accept BASIC + DEVICE as "good enough" for most apps.
    • ✅ Do not chase STRONG integrity unless absolutely necessary [citation:5].
    • ✅ Keep your root manager and modules updated.
    • ✅ If on a custom ROM, ask the maintainer to sign with a release key, not testkey [citation:4].
    • ✅ Back up your working configuration before updating modules.

Tip: Play Integrity is a moving target — Google updates detection regularly. If a module stops working, check the GitHub releases for updates. The community moves fast; a fix that works today may fail next month.
