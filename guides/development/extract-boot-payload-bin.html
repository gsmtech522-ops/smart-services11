Extract boot.img from payload.bin for Rooting

Type
Step-by-Step Guide
Level
Intermediate
Time
~15 minutes
Applies to
OnePlus, Xiaomi, Realme, Pixel, Motorola and other GKI-based devices
Last updated
YYYY-MM-DD

Modern OTA firmware no longer ships loose boot.img / system.img. Everything is compressed inside payload.bin. Extracting boot.img (or init_boot.img on Android 13+) is mandatory before patching with Magisk / KernelSU.

Reference

  1. 1. Prerequisites

    • Full OTA firmware ZIP matching your exact build.
    • 7-Zip or WinRAR.
    • payload-dumper-go binary (or Python 3.x with payload_dumper).
    • ADB & Fastboot installed.

  2. 2. Step 1 — Extract payload.bin from firmware

    1. Download the full OTA zip for your model.
    2. Right-click → extract with 7-Zip.
    3. Locate payload.bin in the extracted folder (1–4 GB+).

  3. 3. Step 2 — Extract boot.img using payload-dumper-go (fastest)

    1. Download the latest payload-dumper-go.exe for Windows.
    2. Place it in the same folder as payload.bin (e.g. C:\extractor).
    3. Open CMD there and extract only the boot partition:
    payload-dumper-go -p boot payload.bin

    For Android 13+ GKI devices, extract init_boot instead:

    payload-dumper-go -p init_boot payload.bin

    Extracted file appears in extracted_... subfolder.

    Alternative — Python payload_dumper:

    pip install payload_dumper
payload_dumper --partitions boot payload.bin

  4. 4. Step 3 — Patch with Magisk

    1. Push the stock image to your phone:
    adb push boot.img /sdcard/Download/
    1. Open Magisk Manager.
    2. Tap Install → Select and Patch a File.
    3. Choose Download/boot.img and patch.
    4. Output: magisk_patched_XXXXX.img saved to Download.
    5. Pull it back to PC:
    adb pull /sdcard/Download/magisk_patched_XXXXX.img .

  5. 5. Step 4 — Flash patched boot via Fastboot

    1. Reboot into Fastboot:
    adb reboot bootloader
fastboot devices
    1. Flash:
    # Standard (Android 12 and older)
fastboot flash boot magisk_patched_XXXXX.img

# Android 13+ GKI / init_boot architecture
fastboot flash init_boot magisk_patched_XXXXX.img
    1. Reboot:
    fastboot reboot

  6. 6. Important warnings

    Android 13+ init_boot distinction: patching boot.img instead of init_boot.img on Android 13+ devices causes a permanent bootloop. Check your ROM structure first.

    Firmware version match: always use the exact build number currently running. Mismatched images cause Wi-Fi, Bluetooth, or touch driver failure.

  7. 7. Troubleshooting

    ProblemFix
    payload_dumper errors on magicFirmware is encrypted (OPPO/Realme .ozip). Extract with the OEM's tool first.
    Bootloop after flashWrong image (init_boot vs boot). Re-flash original stock image, then retry with the correct target.
    fastboot: command not foundInstall Platform Tools; or use .\fastboot in PowerShell.
    Magisk doesn't show rootOEM encryption requires disabling verity/vbmeta first — see DM-Verity guide.
