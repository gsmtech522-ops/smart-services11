How to Extract payload.bin from Android OTA Firmware

Type
Step-by-Step Guide
Level
Intermediate
Time
~10 minutes
Applies to
Google Pixel, OnePlus, Xiaomi, Realme, Motorola, Asus, and all Android 10+ A/B devices
Last updated
YYYY-MM-DD

Modern Android OTA firmware packages no longer ship loose boot.img, system.img or vendor.img files. Instead, all partitions are packed inside a single payload.bin container, which is further stored inside the OTA .zip along with a payload_properties.txt file. Extracting partitions from payload.bin is a mandatory step for rooting with Magisk, custom ROM installation, or firmware analysis.

Reference

  1. 1. What is payload.bin?

    payload.bin is an Android OTA payload — a compressed, chunk-based archive introduced with Android 7 (Pixel) and mandatory since Android 10 for A/B devices. It contains:

    • Manifest — a protobuf-encoded index of all partitions and their block ranges
    • Partition images — boot, system, vendor, product, odm, system_ext, vbmeta, dtbo, super (for dynamic partitions), modem, preloader (on some devices)
    • Delta data — if the OTA is incremental, only changed blocks are stored

    Because it is not a standard ZIP, tools like 7-Zip cannot extract it — you need a payload dumper.

    OTA zip structure:

    firmware.zip
├── payload.bin
├── payload_properties.txt
├── care_map.pb
├── metadata
└── META-INF/
    └── com/
        └── android/
            ├── metadata
            └── otacert

  2. 2. Prerequisites

    • Full OTA firmware ZIP matching your device's exact build number.
    • 7-Zip or WinRAR for extracting the ZIP.
    • Payload dumper tool (Go or Python version).
    • At least 8–30 GB free disk space — extracted partitions total 5–15 GB typically.
    • Windows 10/11, Linux, or macOS.

    Full OTA only: incremental/delta OTAs only contain changes from a previous build. Their payload.bin cannot be extracted to full partition images. Always download the Full OTA for your exact current build.

  3. 3. Step 1 — Extract the OTA zip

    1. Download the Full OTA zip for your device.
    2. Right-click the zip → 7-Zip → Extract to folder.
    3. Inside the extracted folder, locate payload.bin (usually 1–4 GB) and payload_properties.txt.

    Copy payload.bin to a working folder where you will run the extractor, e.g. C:\payload_extract\.

  4. 4. Method 1 — payload-dumper-go (fastest, recommended)

    A single-binary Go tool that extracts partitions in seconds. No Python installation needed.

    Step 1 — Download the binary.

    Get the latest release from GitHub: ssut/payload-dumper-go. Download the .exe for Windows (or the Linux binary for Linux).

    Step 2 — Place everything in one folder.

    C:\payload_extract\
├── payload-dumper-go.exe
└── payload.bin

    Step 3 — Extract ALL partitions:

    payload-dumper-go payload.bin

    Output partitions appear in a folder named extracted_YYYYMMDD_HHMMSS\.

    Step 4 — Extract only specific partitions (faster, saves space):

    # Extract only boot.img (for Magisk root)
payload-dumper-go -p boot payload.bin

# Extract boot and vbmeta together
payload-dumper-go -p boot,vbmeta payload.bin

# Extract super (dynamic partitions) and dtbo
payload-dumper-go -p super,dtbo payload.bin

# Extract init_boot (Android 13+ devices)
payload-dumper-go -p init_boot payload.bin

    Step 5 — Specify output folder manually:

    payload-dumper-go -o output_folder payload.bin

    Step 6 — List partitions without extracting:

    payload-dumper-go -l payload.bin

  5. 5. Method 2 — Python payload_dumper (cross-platform)

    Useful if you prefer Python or need to run on macOS without Go.

    Step 1 — Install.

    pip install payload_dumper

    Step 2 — Extract all partitions.

    payload_dumper payload.bin

    Step 3 — Extract specific partitions.

    # Extract only boot
payload_dumper --partitions boot payload.bin

# Multiple partitions
payload_dumper --partitions boot,system,vendor payload.bin

# Custom output directory
payload_dumper --out output_folder payload.bin

    Step 4 — Extract incremental OTA (advanced, requires old images):

    payload_dumper --diff --old_images ./old_firmware/ payload.bin

    This works only when you provide the exact previous build's partition images.

  6. 6. Method 3 — payload_dumper source script (manual)

    If the pip package does not work for your Python version, clone and run the source directly.

    git clone https://github.com/vm03/payload_dumper.git
cd payload_dumper
pip install -r requirements.txt
python payload_dumper.py payload.bin

    After extraction, you will typically see:

  8. 8. Verify extracted images

    After extraction, confirm each partition is valid before using:

    Check filesystem type:

    file boot.img
file system.img
file super.img

    Check magic bytes manually:

    # First 4 bytes of any image
xxd -l 4 boot.img

# For ext4, magic 53EF appears at offset 1080
xxd -l 4 -s 1080 system.img

# For sparse, magic 3AFF26ED appears at offset 0
xxd -l 4 system.img

    Verify sizes make sense:

    # Windows PowerShell
Get-ChildItem *.img | Select-Object Name, @{N='MB';E={[math]::Round($_.Length/1MB,2)}}

  9. 9. Common use cases

    Root with Magisk:

    1. Extract boot.img (or init_boot.img on Android 13+).
    2. Push to device: adb push boot.img /sdcard/Download/
    3. Open Magisk → Install → Select and Patch a File.
    4. Pull patched image and flash via fastboot: 
      fastboot flash boot magisk_patched_XXXXX.img

    Extract super.img partitions:

    1. Extract super.img with payload-dumper-go.
    2. Convert to raw: simg2img super.img super_raw.img
    3. Use lpunpack to split into individual partitions.
    4. Modify and repack with lpmake.

    Backup modem/IMEI partitions:

    1. Extract modemst1, modemst2, fsg.
    2. Store in cloud (they contain your IMEI calibration).

  10. 10. Troubleshooting

    ProblemFix
    "Unsupported payload version"Incremental OTA — download Full OTA instead.
    Extractor hangs or crashesInsufficient RAM (needs 4 GB+). Close other apps.
    Extracted images are 0 KBDelta OTA — Full OTA required. Or payload.bin truncated.
    "No partitions extracted"Wrong option syntax. Use -p with partition names, or -l to list first.
    Extracted boot.img won't patch in MagiskWrong file — Android 13+ needs init_boot.img instead of boot.img.
    Cannot extract super.img partitionssuper.img must be converted to raw with simg2img first, then lpunpack.
    Out of disk spaceFull extraction needs 10–30 GB. Extract only needed partitions.
    payload_dumper: ModuleNotFoundErrorRun pip install -r requirements.txt in the cloned folder.

  11. 11. Complete command reference

    # ---- Extract OTA zip first ----
# Right-click .zip → 7-Zip → Extract to folder

# ---- payload-dumper-go (Go, fastest) ----
payload-dumper-go payload.bin                                # all
payload-dumper-go -p boot payload.bin                        # boot only
payload-dumper-go -p boot,init_boot,vbmeta payload.bin       # select
payload-dumper-go -p super,dtbo,modem payload.bin            # super etc.
payload-dumper-go -o output_folder payload.bin               # custom dir
payload-dumper-go -l payload.bin                             # list only

# ---- Python payload_dumper ----
pip install payload_dumper
payload_dumper payload.bin
payload_dumper --partitions boot payload.bin
payload_dumper --partitions boot,system,vendor payload.bin
payload_dumper --out output_folder payload.bin
payload_dumper --diff --old_images ./old/ payload.bin

# ---- Manual source script ----
git clone https://github.com/vm03/payload_dumper.git
cd payload_dumper
pip install -r requirements.txt
python payload_dumper.py payload.bin

# ---- Verify output ----
file boot.img
file system.img
xxd -l 4 -s 1080 system.img       # 53EF = ext4
xxd -l 4 boot.img                 # 3AFF26ED = sparse

# ---- Convert sparse if needed ----
simg2img system.img system_raw.img
img2simg system_raw.img system_sparse.img

  12. 12. Best practices

    • ✅ Always download the Full OTA — incremental payloads cannot be fully extracted.
    • ✅ Match the exact build number currently running on your device.
    • ✅ Extract only what you need — saves time and disk space.
    • ✅ Verify extracted images with file and xxd before using.
    • ✅ For Android 13+, always use init_boot.img for Magisk, not boot.img.
    • ✅ Back up modemst1, modemst2, fsg if you extracted them — they contain IMEI calibration.
    • ✅ Keep the original OTA zip in case you need to re-extract.

Tip: after extracting boot.img (or init_boot.img) for Magisk patching, always disable DM-Verity and AVB via fastboot --disable-verity --disable-verification flash vbmeta vbmeta.img before flashing custom recovery or modified partitions. Otherwise the device will bootloop.
