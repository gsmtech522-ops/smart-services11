Extract recovery.img from recovery.img.lz4

Modern firmware often ships partition images compressed as .lz4 — especially Samsung. To root with Magisk, patch stock recovery, or build a custom TWRP, you must first extract the raw recovery.img from recovery.img.lz4.

Reference

  1. 1. What is an LZ4 file?

    LZ4 is a lossless compression algorithm focusing on extremely fast compression/decompression. Android OEMs use it to reduce firmware size without slowing restoration. Standard tools like WinRAR or 7-Zip cannot extract individual .img files without the LZ4 binary.

  2. 2. Method 1 — Windows (recommended)

    Prerequisites:

    • recovery.img.lz4 file (extracted from AP or firmware zip).
    • LZ4 Binary Tool for Windows (official release).

    Step-by-step:

    1. Download & extract the LZ4 tool → you'll see lz4.exe.
    2. Copy recovery.img.lz4 into the same folder as lz4.exe.
    3. Drag-and-drop trick: click and drag recovery.img.lz4 onto the lz4.exe icon and release.
    4. A brief CMD window flashes — decompression runs.
    5. Within seconds, recovery.img appears in the same folder.

    Alternative — Command line:

    lz4 -d recovery.img.lz4 recovery.img

  3. 3. Method 2 — Android (on-device via ZArchiver)

    1. Install ZArchiver from Play Store.
    2. Navigate to the folder containing recovery.img.lz4.
    3. Tap the file → pop-up menu.
    4. Select "Extract here" or "Extract to .//".
    5. ZArchiver outputs recovery.img in the same directory.

  4. 4. Next steps

    • For Magisk root: transfer recovery.img to your phone, open Magisk → "Select and Patch a File".
    • For Odin flashing: re-compress the patched recovery as .tar using 7-Zip so Odin recognizes it.

  5. 5. Troubleshooting

    ProblemFix
    Corrupted ArchiveFirmware zip corrupted during download. Re-download via SamFirm, Frija or official source.
    lz4.exe crashes instantlyWrong architecture — download the 64-bit build for modern Windows.
    Output is 0 bytesSource .lz4 file is truncated — re-extract from the original firmware zip.
