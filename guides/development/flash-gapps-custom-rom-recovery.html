How to Flash GApps on a Custom ROM

Type
Step-by-Step Guide
Level
Intermediate
Time
~10 minutes
Applies to
AOSP-based custom ROMs (LineageOS, Pixel Experience, crDroid, etc.)
Last updated
YYYY-MM-DD

Critical rule: GApps must be flashed immediately after the ROM, before first boot. If you reboot into Android first and then try to install GApps, you will get crashes and must factory reset [citation:2][citation:4].

Most custom ROMs ship without Google apps due to licensing restrictions. If you flash a "vanilla" (no-GApps) ROM, you must install GApps separately to get Play Store, Play Services and other Google apps. This guide covers the correct workflow, package selection, and recovery steps.

Reference

  1. 1. Which GApps package should you use?

    PackageBest forSizeNotes
    MindTheGappsLineageOS and AOSP ROMs~200 MBOfficially recommended by LineageOS [citation:2]
    NikGAppsAdvanced users who want controlVariableCore package is ~80 MB, addons optional [citation:4]
    OpenGAppsLegacy ROMs (Android 10 and older)150 MB – 1 GBNo longer maintained; use only if ROM specifically requires it [citation:13]

    Recommendation: for LineageOS use MindTheGapps matching your Android version. For other AOSP ROMs, NikGApps Core is the safest minimal choice [citation:4].

  2. 2. Prerequisites

    • Custom recovery installed (TWRP or OrangeFox).
    • Vanilla custom ROM zip (no GApps pre-installed) matching your device.
    • GApps zip matching your Android version and architecture (ARM64 most common).
    • Data backup — the process wipes your device.
    • Charged battery (50%+).

    Match the Android version: GApps for Android 14 will not work on Android 15, and vice versa. Check your ROM's Android version in Settings → About phone after the ROM boots, or on the ROM download page.

  3. 3. Step 1 — Boot into custom recovery

    1. Power off the device completely.
    2. Hold the recovery key combo:
      • Most devices: Volume Up + Power
      • Samsung: Volume Up + Bixby + Power
      • Xiaomi/POCO: Volume Up + Power
    3. Release when the TWRP/OrangeFox logo appears.

  4. 4. Step 2 — Clean flash workflow (ROM + GApps together)

    This is the safe method. Flash the ROM and GApps in one recovery session, without rebooting in between.

    Step A — Wipe (if coming from another ROM):

    1. Go to Wipe → Advanced Wipe.
    2. Select Dalvik/ART Cache, System, Data, Cache.
    3. Swipe to wipe.
    4. Go back → Format Data → type yes (this removes encryption).
    5. Reboot to recovery again (needed after Format Data).

    Step B — Flash ROM:

    1. Go to Install → select the ROM zip.
    2. Swipe to flash.
    3. Do NOT reboot yet.

    Step C — Flash GApps:

    1. Go back to Install (do not reboot).
    2. Select the GApps zip.
    3. Swipe to flash.
    4. If you see a message that GApps size is too large, you must use a smaller package (e.g. NikGApps Core instead of Stock).

    Step D — Wipe cache and reboot:

    1. Go to Wipe → wipe Cache and Dalvik/ART Cache.
    2. Reboot to System.

    ADB Sideload alternative: if your recovery supports it (LineageOS Recovery, some TWRP builds), you can flash via PC: adb sideload rom.zip then adb sideload gapps.zip without rebooting [citation:1].

  5. 5. Step 3 — First boot and setup

    1. Wait 5–10 minutes for the first boot.
    2. Sign in with your Google account during setup.
    3. Open Play Store and verify it works.
    4. Check Settings → Apps → Google Play Services — it should show as installed and active.

    If Play Store crashes: clear cache/data of com.android.vending and com.google.android.gms in Settings → Apps. If that fails, you flashed GApps after first boot — you must factory reset and redo the process [citation:2].

  6. 6. Alternative — Flash GApps only (ROM already flashed)

    If you already flashed the ROM but did not reboot into Android yet, you can still flash GApps:

    1. In recovery, go to Install.
    2. Select the GApps zip.
    3. Swipe to flash.
    4. Wipe cache/Dalvik and reboot.

    If the ROM already booted into Android once: you must go back to recovery → Format Data → re-flash ROM + GApps together. There is no way around this — Google Play Services must be present on the first boot [citation:2].

  9. 9. Complete command reference (ADB sideload method)

    # ---- From recovery, enter ADB Sideload mode ----
# LineageOS Recovery: Apply update → Apply from ADB
# TWRP: Advanced → ADB Sideload → Swipe to start

# ---- Verify PC sees the device ----
adb devices
# Should show: xxxxxx    sideload

# ---- Flash ROM first ----
adb sideload rom.zip

# ---- Without rebooting, flash GApps ----
adb sideload gapps.zip

# ---- Reboot to system ----
adb reboot

# ---- If bootloop: back to recovery ----
adb reboot recovery
# Then Format Data and redo

  10. 10. Best practices

    • ✅ Flash ROM and GApps in one recovery session — no reboot between them.
    • ✅ Use MindTheGapps for LineageOS, NikGApps Core for others [citation:4][citation:13].
    • ✅ Match the Android version and architecture (ARM64) exactly.
    • ✅ If space runs out, use a smaller GApps package.
    • ✅ Back up data before Format Data — it erases everything.
    • ✅ After each OTA update, re-flash GApps if the ROM does not preserve them.
    • ✅ Do not use OpenGApps unless the ROM explicitly requires it (deprecated).

Tip: if you use a GApps build of the ROM (not vanilla), do not flash GApps separately — they are already included. Flashing again will cause conflicts. Check the ROM filename: "vanilla" = no GApps, "gapps" = GApps included.
