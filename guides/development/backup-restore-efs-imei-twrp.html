How to Backup & Restore EFS / IMEI via TWRP

Type
Step-by-Step Guide
Level
Advanced
Time
~10 minutes
Applies to
Qualcomm Snapdragon & Samsung Exynos devices with TWRP
Last updated
YYYY-MM-DD

Critical warning: the EFS partition holds your device's IMEI numbers, baseband calibration, Wi-Fi/BT MAC addresses and RF tuning data. Losing or corrupting EFS results in:

  • "Invalid IMEI" or "IMEI Null" errors
  • "Baseband: Unknown" in Settings → About phone
  • No signal / Emergency calls only
  • Wi-Fi refusing to turn on

Always back up EFS before flashing, rooting, or installing custom ROMs. And only operate on your own device — IMEI modification is illegal in most countries.

Custom recovery like TWRP or OrangeFox can back up EFS partitions as raw image files that you can restore later if something goes wrong. This is the safest, most reliable method that does not require root access.

Reference

  1. 1. What is EFS and why back it up?

    EFS (Encrypted File System) is a protected partition containing the files that identify your phone to the cellular network:

    PartitionContainsWhere used
    efsIMEI, IMEI2, MAC addresses, calibration certificatesSamsung and some Qualcomm
    modemst1Primary modem NVRAM copyQualcomm
    modemst2Secondary modem NVRAM copy (mirror)Qualcomm
    fsgFile System Golden — protected baseband backupQualcomm
    fscModem file system counterQualcomm
    persistSensor calibration + fingerprint dataAll Android

    Note: on some Qualcomm devices, EFS data lives inside the modem partition or a custom-named partition like fsg. TWRP will show you what's available on your device.

  2. 2. Prerequisites

    • Your device must have a TWRP or OrangeFox custom recovery installed. If not, you need to unlock the bootloader first.
    • A microSD card or OTG USB drive is recommended. Backing up to internal storage is risky — a full wipe removes the backup too.
    • Sufficient free space: 50–500 MB depending on the partitions you back up.
    • Charged battery (at least 50%).

  3. 3. Step 1 — Boot into TWRP recovery

    1. Power off the device completely.
    2. Hold the correct key combination for your model:
      • Most Qualcomm: Volume Up + Power
      • Samsung: Volume Up + Bixby + Power (or Volume Up + Power on older models)
      • Xiaomi / POCO: Volume Up + Power
      • OnePlus: Volume Down + Power → select Recovery
    3. When TWRP opens, swipe to "Allow Modifications" if prompted.

  4. 4. Step 2 — Backup EFS partitions

    1. From the TWRP main menu, tap Backup.
    2. You will see a list of partitions. Only tick the ones that matter for IMEI:
      • EFS (Samsung / some Qualcomm)
      • Modem (baseband firmware + NVRAM)
      • Modemst1 and Modemst2 (Qualcomm NVRAM mirrors)
      • FSG (Qualcomm golden backup)
      • Persist (sensor calibration — optional)
    3. Make sure Storage at the top points to your MicroSD card (or OTG drive). Never back up to internal storage only.
    4. Tap Select Storage if you need to switch.
    5. Tap Backup (or swipe the slider). TWRP begins creating the archive.
    6. Once complete, TWRP shows: "Backup Complete". Note the folder name — it looks like TWRP/BACKUPS/SERIAL/2026-01-15--12-34-56_LINEAGEOS.
    TWRP/BACKUPS/
└── SERIAL_NUMBER/
    └── 2026-01-15--12-34-56_LINEAGEOS/
        ├── efs.emmc.win
        ├── efs.emmc.win.md5
        ├── modem.emmc.win
        ├── modemst1.emmc.win
        ├── modemst2.emmc.win
        ├── fsg.emmc.win
        └── ...

  5. 5. Step 3 — Copy backup to PC (extra safety)

    Even on SD card, EFS backups are critical. Copy the folder to your PC:

    1. Boot normally into Android.
    2. Connect USB and switch to File Transfer / MTP mode.
    3. Open SD Card → TWRP → BACKUPS → SERIAL_NUMBER and copy the whole folder to D:\EFS_Backup\.
    4. Additionally, copy it to a cloud folder (Google Drive, OneDrive, etc.).

  6. 6. Step 4 — Restore EFS from backup

    Only do this if you have lost IMEI, baseband is "Unknown", or Wi-Fi won't turn on:

    1. Boot into TWRP recovery.
    2. Go to Restore (or Restore from Backup).
    3. Navigate to the folder that contains your EFS backup.
    4. Select the same partitions you backed up (EFS, Modem, Modemst1, Modemst2, FSG).
    5. Tap Restore and swipe to confirm.
    6. Wait for the "Restore Complete" message.
    7. Reboot to system.

    Verification: after reboot, dial *#06# — both IMEI numbers should appear. Settings → About phone should show your baseband version (not "Unknown").

  7. 7. Alternative — TWRP terminal backup (for advanced users)

    If a partition is not listed in the TWRP Backup GUI (rare), you can back it up manually using the built-in terminal:

    1. In TWRP → Advanced → Terminal.
    2. Identify the partition block:
    ls -l /dev/block/bootdevice/by-name/ | grep -E 'efs|modem'

    You will see something like:

    lrwxrwxrwx  root  root   efs -> /dev/block/mmcblk0p21
lrwxrwxrwx  root  root   modem -> /dev/block/mmcblk0p22
lrwxrwxrwx  root  root   modemst1 -> /dev/block/mmcblk0p10
lrwxrwxrwx  root  root   modemst2 -> /dev/block/mmcblk0p11
    1. Dump each partition to your SD card:
    dd if=/dev/block/bootdevice/by-name/efs of=/external_sd/efs.img
dd if=/dev/block/bootdevice/by-name/modem of=/external_sd/modem.img
dd if=/dev/block/bootdevice/by-name/modemst1 of=/external_sd/modemst1.img
dd if=/dev/block/bootdevice/by-name/modemst2 of=/external_sd/modemst2.img

    To restore a dumped image:

    dd if=/external_sd/efs.img of=/dev/block/bootdevice/by-name/efs
dd if=/external_sd/modem.img of=/dev/block/bootdevice/by-name/modem

    Danger: dd writes raw bytes. If the output path is wrong, you can brick the phone. Double-check the block device name and size every time.

  8. 8. Samsung-specific EFS backup

    Samsung phones store IMEI in the efs partition, split into efs.img and efs.img.ext4. TWRP on Samsung shows EFS as a single backup option — that covers both. Restore works the same way.

    To back up via ADB shell on a rooted Samsung:

    adb shell su
dd if=/dev/block/by-name/efs of=/sdcard/efs.img
exit
adb pull /sdcard/efs.img D:\Backups\

  9. 9. Qualcomm EDL backup (deeper safety net)

    If your phone is completely dead (no recovery), you can still extract NVRAM via EDL mode using QFIL or QPST. See the Qualcomm guides for details. TWRP backup is the primary safety net — EDL is the recovery-of-last-resort.

  10. 10. Troubleshooting

    ProblemFix
    EFS not listed in TWRP BackupYour device's TWRP build does not expose EFS. Use the terminal dd method in section 7.
    Restore fails with "unable to mount efs"Wrong filesystem — restore may need ext4 compatibility. Use an updated TWRP or the terminal method.
    IMEI still invalid after restoreTry restoring modemst1 and modemst2 as well, then reboot into bootloader and back to system.
    Baseband still "Unknown"The fsg partition is also required. Ensure both modem and fsg are restored.
    Wi-Fi still off after restoreWi-Fi MAC is stored in persist. Restore persist too — but only from a backup of the same device.
    TWRP ignores microSDCard format may be exFAT — TWRP supports it but may need "Mount" tab. Or use a USB OTG drive.

  11. 11. What NOT to do

    • 🚫 Do not use another person's EFS backup — it contains their IMEI. That is illegal and will not work.
    • 🚫 Do not use the "Format Data" option in TWRP without first backing up EFS. Format Data erases internal storage but not EFS — yet flashing a wrong firmware might.
    • 🚫 Do not attempt to modify IMEI numbers directly. Only restore your own backup.
    • 🚫 Do not trust "EFS repair" tools claiming to generate IMEI — that's illegal.

Tip: after installing any custom ROM, immediately reboot into TWRP and take a fresh EFS backup. Also, keep a copy of your backup on Google Drive or a secondary USB drive — SD cards can fail.
