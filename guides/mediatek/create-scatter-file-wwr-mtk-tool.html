Create a Scatter File Using WWR MTK Tool

Type
Step-by-Step Guide
Level
Intermediate
Time
~15 minutes
Applies to
MediaTek devices without stock firmware
Last updated
YYYY-MM-DD

Without stock firmware, SP Flash Tool can't determine memory addresses for Readback or flashing. WWR MTK Tool solves this — it analyzes a raw ROM_0 dump and generates a precise Android_scatter.txt along with exact memory addresses.

Reference

  1. 1. Prerequisites

    • WWR MTK Tool (v2.51 or newer).
    • HxD Hex Editor (optional, for inspecting dumps).
    • An initial ROM_0 dump (16 MB to 32 MB) from SP Flash Tool Readback with start 0x0 and length 0x2000000.

  2. 2. Step 1 — Initial partial readback in SP Flash Tool

    1. Open SP Flash Tool — do NOT load a scatter file.
    2. Go to Readback tab → Add.
    3. Double-click the entry, save as ROM_0.
    4. In the popup:
      • Region: EMMC_USER
      • Start Address: 0x0000000000000000
      • Length: 0x0000000002000000 (32 MB)
    5. Click Readback, connect powered-off phone, wait for green checkmark.

  3. 3. Step 2 — Load ROM_0 into WWR MTK Tool

    1. Launch WWR MTK Tool.
    2. Go to Auto-mode tab (or click Select file).
    3. Click Open file → select ROM_0.
    4. WWR auto-analyzes: identifies platform (MT6763, MT6765, MT6785…), locates GPT/PMT partition table.

  4. 4. Step 3 — Parse & generate scatter

    1. WWR displays all partitions (preloader, pgpt, boot, recovery, system, vendor…) with start addresses and sizes.
    2. Confirm chipset when prompted.
    3. Click Create Android scatter file (bottom right).
    4. Save as MT67xx_Android_scatter.txt.

  5. 5. Step 4 — Extract readback addresses for full backup

    1. In WWR, switch to Readback tab.
    2. Note the Preloader and ROM_1 (EMMC_USER) start & length values.
    3. Copy the full dump length.
    4. In SP Flash Tool, load your new scatter, paste addresses into Readback tab.
    5. Click Readback → full ROM dump extracted.

    Pro tip: verify the generated scatter includes the preloader partition. If WWR warns "missing preloader", manually select a matching preloader binary for your chipset before saving.
