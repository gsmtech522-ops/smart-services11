Flash MediaTek Firmware via MTKClient

Type
Step-by-Step Guide
Level
Advanced
Time
~15 minutes
Applies to
Modern Helio/Dimensity chips with SLA/DAA protection
Last updated
YYYY-MM-DD

Modern MTK devices (Helio, Dimensity) block SP Flash Tool without OEM auth. MTKClient exploits BROM to bypass SLA/DAA entirely, letting you flash raw partition binaries or full firmware folders completely free.

Reference

  1. 1. Prerequisites

    • MTKClient (Python environment) set up.
    • MediaTek VCOM drivers installed.
    • LibUSB-win32 filter or UsbDk driver installed.
    • Unpacked firmware images (.img files) or full firmware folder.

  2. 2. Method 1 — Flash via GUI (visual method)

    1. Open CMD inside mtkclient.
    2. Launch GUI:
    python mtk_gui.py
    1. Power off phone.
    2. Hold Volume Up+Volume Down, connect USB.
    3. MTKClient bypasses auth and shows partition table.
    4. Go to Write Partition(s) tab.
    5. Select partition (boot, recovery, vbmeta, super…).
    6. Click Browse → select corresponding .img.
    7. Click Write Partition(s) and wait for 100%.

  3. 3. Method 2 — Flash via CLI (faster)

    1. Open CMD inside mtkclient as Administrator.
    2. Place your .img files in the folder or note their paths.
    3. Execute the write command (turn off phone, hold volume keys, plug USB for each execution):
    # Flash boot
python mtk w boot boot.img

# Flash recovery
python mtk w recovery recovery.img

# Flash vbmeta
python mtk w vbmeta vbmeta.img

# Flash super (dynamic partitions)
python mtk w super super.img

    Flash full firmware folder:

    python mtk wl path/to/firmware_folder/

    MTKClient auto-matches image names to GPT and sequentially flashes every partition.

  4. 4. Step 4 — Factory reset & reboot

    python mtk e metadata,userdata

    Unplug, hold Power 10s to exit BROM and boot.

  5. 5. Troubleshooting

    LIBUSB_ERROR_NOT_SUPPORTED / device disconnecting

    Fix: reinstall UsbDk drivers, or filter the MediaTek USB port with LibUSB Filter Driver.

    FAILED (remote: Write protected)

    Fix: some partitions (preloader, bootloader) are write-protected. Run python mtk da spa first.

    Stuck on first boot loop

    Fix: boot into Stock Recovery → Wipe Data / Factory Reset, or run python mtk e userdata.
