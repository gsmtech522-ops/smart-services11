Where to Find MTK Database Files (BPLGU & MDDB)

Type
Reference Guide
Level
Intermediate
Time
~10 minutes
Applies to
All MediaTek devices needing SN Writer / Maui META
Last updated
YYYY-MM-DD

If you use Transsion AfterSales Tool, SN Writer, or MauiMETA for network repair, MTK database files are mandatory. Without them, the tool throws "Database File Missing" or "Failed to Parse Radio Parameter."

The two types are:

  • BPLGUInfoCustomAppSrcP… — modem database for 2G/3G/4G radio configurations
  • MDDB.META… or APDB… — newer LTE/5G processor architecture database

Reference

  1. 1. Method 1 — Extract from official stock firmware

    Scenario A — Standard scatter firmware:

    1. Open the extracted firmware folder.
    2. Look for database or DB sub-folder.
    3. If none, look alongside boot.img and system.img.
    4. Scan for files starting with BPLGUInfo… or MDDB… and copy them to your desktop.

    Scenario B — Compressed firmware (Oppo/Realme .ofp, Xiaomi .tgz):

    1. Download a firmware extraction tool matching the brand (Oppo OFP Extractor, Payload.bin Dumper).
    2. Extract the container until raw images are visible.
    3. Locate the integrated MDDB / BPLGU files in the extracted directory.

  2. 2. Method 2 — Pull from a live Android device via ADB

    If you have a working phone of the same model, pull the database files directly. Android keeps a local copy so the modem can load them during boot.

    Step 1 — Enable USB Debugging and authorize PC.

    Step 2 — Locate the files:

    adb shell "find /vendor/etc/mddb/ /system/etc/mddb/ /vendor/nvram/ -name '*BPLGU*' -o -name '*MDDB*'"

    Step 3 — Pull the files:

    # For newer devices
adb pull /vendor/etc/mddb/ C:\Users\Public\Desktop\

# For older MTK directories
adb pull /system/etc/firmware/ C:\Users\Public\Desktop\

    You now have authentic factory database files on your desktop, ready for SN Writer or META.
