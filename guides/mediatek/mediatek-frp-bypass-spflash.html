Bypass FRP on MediaTek via SP Flash Tool

Type
Advanced Guide
Level
Advanced
Time
~10 minutes
Applies to
MediaTek devices with scatter file available
Last updated
YYYY-MM-DD

Legal warning: this guide is only for your own device or a device you are authorized to service. Removing FRP from someone else's phone is theft, illegal in most countries, and traceable to the service provider.

Factory Reset Protection (FRP) is an Android security feature that blocks unauthorized access after a hard reset. On MediaTek devices, the FRP flag resides in the frp partition. Instead of "Format All + Download" (which wipes IMEI), you can perform a targeted manual format of just the frp block using exact hex addresses — in under 5 seconds.

Reference

  1. 1. Prerequisites

    • Official MediaTek VCOM/Preloader drivers installed.
    • SP Flash Tool (v5.x or v6.x matching your SoC).
    • Scatter file for your exact model (from stock firmware, or generated via WWR MTK Tool).
    • Text editor (Notepad++ or VS Code) to inspect the scatter file.
    • USB cable + charged MediaTek device.
    • Optional: MTK Auth Bypass Tool / MTKClient for modern SLA/DAA-protected SoCs.

  2. 2. Step 1 — Extract FRP physical memory address

    1. Open your stock firmware folder and locate the scatter file (e.g. MT6765_Android_scatter.txt).
    2. Right-click and choose Edit with Notepad++.
    3. Ctrl+F → search partition_name: frp → Find Next.
    4. Scroll to the block and note two keys:
      • linear_start_addr: → physical start address
      • partition_size: → format length

    Example scatter entry:

    - partition_index: SYS21
  partition_name: frp
  file_name: NONE
  is_download: false
  type: NORMAL_ROM
  linear_start_addr: 0x2d80000
  physical_start_addr: 0x2d80000
  partition_size: 0x100000
  region: EMMC_USER
    • Begin Address [HEX]: 0x2d80000
    • Format Length [HEX]: 0x100000

    CRITICAL: never use example addresses from other devices. Physical start addresses vary across SoCs and partition tables. Wrong addresses will overwrite bootloaders or NVRAM — hard-bricking the phone or corrupting IMEI.

  3. 3. Step 2 — Configure SP Flash Tool

    1. Launch flash_tool.exe as Administrator.
    2. In Download tab, choose Download-Agent → MTK_AllInOne_DA.bin (or OEM DA).
    3. Choose Scatter-loading File → your Android_scatter.txt.
    4. Switch to Format tab.
    5. Select Manual Format Flash (do NOT choose Auto Format or Format All).
    6. Set region as EMMC_USER (or match scatter's region — UFS_LU0 on UFS devices).
    7. Paste the extracted values:
      • linear_start_addr → Begin Address [HEX]
      • partition_size → Format Length [HEX]

  4. 4. Step 3 — Execute the format

    1. If the SoC is SLA/DAA-protected, run your auth bypass first (e.g. MTKClient, MTK Auth Bypass Tool).
    2. Click Start in the Format tab.
    3. Power off the phone completely.
    4. Hold Volume Down (or Volume Up+Volume Down) and connect USB.
    5. Watch SP Flash Tool detect the Preloader/BROM COM port — red bar (DA), then green progress.
    6. Green checkmark Format OK appears in 1–3 seconds — the frp block is wiped.
    7. Disconnect, hold Power to boot, and complete the initial setup — the Google FRP prompt no longer appears.

  5. 5. Troubleshooting

    BROM ERROR: S_DL_GET_DRAM_SETTINGS_FAIL (5054)

    Cause: DA and RAM communication failure.

    Fix: install proper VCOM drivers, use OEM-matched DA file, verify scatter authenticity.

    STATUS_SEC_AUTH_FILE_NEEDED / SLA handshake fail

    Cause: hardware secure boot requires auth tokens.

    Fix: run MTKClient payload or an auth bypass tool before Start.

    Phone boot loops after format

    Cause: wrong hex start/length wiped neighboring partitions.

    Fix: re-flash full stock firmware via Download Only mode.
