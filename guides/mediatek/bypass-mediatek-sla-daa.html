Bypass MediaTek SLA/DAA Security Protection

Type
Advanced Guide
Level
Advanced
Time
~10 minutes
Applies to
Helio P/G and Dimensity chipsets
Last updated
YYYY-MM-DD

Modern MediaTek SoCs (Helio, Dimensity) enforce SLA (Serial Link Authentication) and DAA (Download Agent Authentication). These block unauthorized servicing tools — forcing technicians to use paid authorization or OEM servers.

Without bypassing, tools throw errors like STATUS_SEC_AUTH_FILE_NEEDED (0xC0020002) or BROM ERROR: 6047.

Reference

  1. 1. What are SLA and DAA?

    • SLA: a cryptographic handshake between Boot ROM and an online OEM server verifying flashing authorization.
    • DAA: validates the DA.bin signature inside SP Flash Tool, preventing custom or modified binaries.

    Bypassing temporarily disables signature verification in the CPU's SRAM, allowing tools like SP Flash Tool, Miracle Box, or UnlockTool to communicate without an .auth file.

  2. 2. Prerequisites

    • MediaTek VCOM / Preloader drivers installed.
    • LibUSB-win32 filter driver package installed.
    • MTK Auth Bypass Tool (or MCT utility / MTKClient).

  3. 3. Step 1 — Install LibUSB driver filter

    1. Launch install-filter-driver.exe from the LibUSB package.
    2. Power off the phone.
    3. Hold volume keys, connect USB.
    4. Locate MediaTek PreLoader USB VCOM or MTK USB Port in LibUSB, select it, click Install.

  4. 4. Step 2 — Bypass via MTK Auth Bypass Tool

    1. Open MTK Auth Bypass Tool.
    2. Leave the default Auto-detect settings.
    3. Click Bypass. Log shows: Waiting for MTK USB device…
    4. Power off the device.
    5. Hold Volume Up+Volume Down, plug USB.
    6. The tool logs success: 
      Device Found!
      Hardware ID: MT6765 [Helio P35]
      Disable Watchdog... OK
      Bypass SLA / DAA... OK
      Protection Disabled Successfully!
      COM Port Assigned: COM14
    7. DO NOT disconnect USB — the watchdog is now frozen on the assigned COM port.

  5. 5. Step 3 — Use SP Flash Tool without auth file

    1. Launch SP Flash Tool.
    2. Load your scatter file.
    3. Leave the Authentication File (.auth) field BLANK.
    4. Options → Option → Connection tab:
      • Choose UART (or USB)
      • Select the COM Port assigned by the Auth tool (e.g. COM14)
      • Baud Rate: 921600 or 115200
    5. Close Options, click Download — flashing proceeds without auth.

  6. 6. Alternative — Command line (MTKClient)

    cd mtkclient
python mtk payload

    Connect the powered-off device with volume keys held. MTKClient sends the payload, disables SLA/DAA, and exposes a clean COM port.

  7. 7. Troubleshooting

    Phone reboots into charging mode before LibUSB capture

    Fix: unplug, hold Power + Volume Down 10s to hard reset. Open LibUSB filter installer first, then plug cable with volume keys held.

    SP Flash Tool hangs on Download DA 0%

    Fix: verify COM Port and Baud Rate match the Auth tool output, or switch connection mode between USB and UART.

    Does auth bypass wipe user data or IMEI?

    Fix: No. It only freezes the hardware security watchdog in SRAM — no data is altered.
