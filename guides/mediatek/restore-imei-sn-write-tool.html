Restore Null/Invalid IMEI via SN Write Tool

Type
Advanced Guide
Level
Advanced
Time
~15 minutes
Applies to
Dual SIM MediaTek devices with wiped NVRAM
Last updated
YYYY-MM-DD

Legal warning: only restore the original IMEI of your own device. Changing IMEI is illegal in most countries (Pakistan: PTA, India: DoT, USA: FCC). The IMEI is printed on the box or battery label.

After full firmware flash, format operations, or NVRAM corruption, MTK phones often lose cellular credentials → "Invalid IMEI", "Null IMEI", or "No Service". SN Write Tool is the official MediaTek utility to write IMEI, Wi-Fi MAC, Bluetooth MAC, and serial numbers into NVRAM by parsing modem database files.

Reference

  1. 1. Prerequisites

    • MTK VCOM / CDC USB drivers installed.
    • SN Write Tool (v2.x or v5.x).
    • BPLGU modem database file from stock firmware.
    • APDB file from stock firmware.
    • Original 15-digit IMEI numbers (from box or battery label).
    • Quality USB cable + charged device.

  2. 2. Step 1 — Extract database files

    1. Unpack your device's official stock firmware.
    2. Locate BPLGUInfoCustomAppSrcP_... (modem database).
    3. Locate APDB_... (AP database).
    4. Copy both files to a clean folder on your desktop.

  3. 3. Step 2 — Configure SN Write Tool

    1. Extract the SN Write Tool zip and run SN Write Tool.exe as Administrator.
    2. Set ComPort dropdown → USB VCOM.
    3. Set Target Type → Smart Phone (or Feature Phone for legacy MT6261).
    4. Click System Config.
    5. In Write Option, check:
      • IMEI
      • Dual IMEI (for dual SIM devices)
    6. Optional: check Wi-Fi Address / BT Address for missing MAC.
    7. In Database File:
      • MD1_DB → browse to BPLGU...
      • AP_DB → browse to APDB...
    8. Click Save.

  4. 4. Step 3 — Execute IMEI writing

    1. Click Start.
    2. A Scan Data popup asks for IMEI strings.
    3. Enter:
      • IMEI 1: primary SIM IMEI
      • IMEI 2: secondary SIM IMEI
    4. Click OK → log shows Wait for Cell Connect...
    5. Power off the phone.
    6. Connect USB (press Volume Down/Up if required for META/Boot).
    7. SN Write Tool switches phone into META Mode, parses DBs, writes IMEI to NVRAM/NVDATA.
    8. Green PASS banner = success.
    9. Unplug, boot, dial *#06# to verify both IMEIs.

  5. 5. Troubleshooting

    Fail to connect / META Mode timeout

    Fix: install MTK CDC drivers manually, ensure phone is completely off before plugging, use SLA/DAA auth bypass on protected chips.

    Load Database File Failed / APDB mismatch

    Fix: extract fresh BPLGU and APDB from the exact stock firmware for your specific build.

    IMEI shows correct but "No Service" remains

    Fix: radio calibration was erased. Restore a valid nvram/nvdata backup or write a working donor dump via Maui META first.
