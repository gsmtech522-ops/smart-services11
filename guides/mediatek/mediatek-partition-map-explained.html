Every MediaTek device organizes eMMC/UFS storage into raw logical blocks — partitions. They are indexed inside a manifest called the scatter file (e.g. MT6765_Android_scatter.txt). Understanding each partition is the difference between a quick repair and a hard-bricked handset with IMEI loss.

Reference

  1. 1. Bootloader & execution partitions

    Boot happens in strict stages. Any missing/corrupted stage = no Android.

    • preloader: primary bootloader. Executed by BROM on power-on. Initializes DRAM, manages USB BROM/VCOM, loads LK.
    • lk / lk2: Little Kernel — the Android bootloader GUI. Handles boot screen, charging indicator, fastboot mode, verified boot checks.
    • boot: Linux Kernel + ramdisk. Handles mounting root FS during Android startup. Modified by Magisk for root.
    • vendor_boot: Android 11+ (GKI). Splits OEM vendor kernel modules and ramdisk from generic kernel in boot.
    • recovery: Minimal Linux OS for emergency install, factory reset, OTA updates. On A/B seamless devices, integrated inside boot.

  2. 2. Security, locking & configuration partitions

    • frp: Google Factory Reset Protection flag and account lock parameters.
    • seccfg: Bootloader unlock flag and digital signature structures.
    • proinfo: Factory-injected device identifiers — OEM model number, region codes, serial numbers.
    • tee1 / tee2: TrustZone binaries, Keystore/Keymaster, DRM certs (Widevine L1), biometric hashes.

  3. 3. Baseband, radio & IMEI partitions

    Formatting these destroys network connectivity. Never use "Format All + Download" without NVRAM/IMEI backup.

    • nvram: permanent cellular calibration, dual IMEI, Wi-Fi/BT MAC, RF power tuning.
    • nvdata: dynamic runtime NVRAM parameters updated by Android. Located under /vendor/nvdata.
    • nvram_cust / protect1 / protect2: hardware protection blocks mirroring critical NVRAM data. Prevent corruption during OTA or power loss.
    • md1img / md1dsp: baseband modem firmware required for SIM and cell-tower communication.

  4. 4. OS & user storage partitions

    • system / super: core Android OS. On Android 10+, system, vendor, product merged into dynamic super.
    • vendor: OEM HAL drivers for camera, sensors, audio, GPU.
    • userdata: largest partition — apps, photos, videos, PIN/pattern/password.
    • metadata: FBE (File-Based Encryption) keys — must wipe with userdata.
    • persist: persistent hardware calibration (camera sensor alignment, sensors, factory test values).
