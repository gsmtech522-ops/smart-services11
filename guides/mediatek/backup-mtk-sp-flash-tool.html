Backup MediaTek Firmware via SP Flash Tool (Readback)

Type
Step-by-Step Guide
Level
Intermediate
Time
~15 minutes
Applies to
All MTK devices with scatter file
Last updated
YYYY-MM-DD

Before flashing custom ROMs, rooting, or hardware repairs, a full stock firmware backup is the safest precaution. SP Flash Tool's built-in Readback feature extracts complete raw partition dumps directly from the phone's storage.

Reference

  1. 1. Prerequisites

    • MediaTek VCOM / Preloader drivers installed.
    • Latest compatible SP Flash Tool.
    • Device's original Android_scatter.txt (or generated via WWR MTK Tool).

  2. 2. Step 1 — Load scatter file

    1. Launch flash_tool.exe as Administrator.
    2. In Download tab, choose the scatter file (MT67xx_Android_scatter.txt).
    3. SP Flash Tool displays the device's partition map.

  3. 3. Step 2 — Switch to Readback tab & configure output

    1. Click Readback tab.
    2. Click Add to add a new entry.
    3. Double-click the file path line.
    4. Choose a save folder, name the file (ROM_0 or boot.img), click Save.

  4. 4. Step 3 — Set hex addresses

    A Readback item address popup appears:

    1. Type: Hex
    2. Region: EMMC_USER (or UFS_LUN0 for UFS)
    3. Start Address:
      • Full backup: 0x0000000000000000
      • Specific partition: copy the partition's linear_start_addr
    4. Length: copy partition size from scatter; for full dump, copy userdata start address to get everything.
    5. Click OK.

    Pro tip: if you don't know exact addresses, load your initial ROM_0 into WWR MTK Tool — it calculates hex start/length for every partition.

  5. 5. Step 4 — Execute readback

    1. Click green Readback button.
    2. Power off the phone.
    3. Hold Volume Down (or both volume keys) and connect USB.
    4. Watch: Red bar (DA Download) → Blue/Yellow bar (Readback).
    5. Green checkmark Readback OK confirms success.
    6. Unplug.

  6. 6. Step 5 — Extract partition images (optional)

    If you saved a full ROM_0 dump, use WWR MTK Tool:

    1. Open WWR MTK Tool.
    2. Load ROM_0.
    3. Use the Cut/Split ROM feature to slice it into individual .img files.
