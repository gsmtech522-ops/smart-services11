Install MediaTek (MTK) VCOM Drivers on Windows

Type
Step-by-Step Guide
Level
Beginner
Time
~10 minutes
Applies to
Windows 7, 8, 10, 11
Last updated
YYYY-MM-DD

For any MediaTek (MTK) repair — flashing firmware, running SP Flash Tool, CM2, Miracle Box, or MTKClient — the first step is installing the correct USB drivers. Without MTK VCOM drivers, your PC will not detect the phone in Preloader/BROM mode, and every servicing tool will fail with connection errors.

Reference

  1. 1. Prerequisites (crucial step)

    Before installing — especially on Windows 8, 10, or 11 — you must disable Driver Signature Enforcement. Windows blocks unsigned drivers by default, which is the #1 reason MTK driver setup fails.

    Windows blocks unsigned drivers. Follow the "Disable Driver Signature Enforcement" guide first, or the MTK driver installation will show "cannot verify publisher" and fail.

  2. 2. Method 1 — Automatic installation (easiest)

    1. Download & extract the MediaTek Driver package (from trusted sources like mtkdriver.com or the official MediaTek support page). Use WinRAR or 7-Zip.
    2. Locate the setup file inside the extracted "Auto-Installer" folder.
    3. Run Installer: right-click Install.exe or DriverInstall.exe → Run as Administrator.
    4. Begin setup: click Install when the wizard launches.
    5. Complete & reboot: wait for the "Success" message, click Finish, and restart your PC.

  3. 3. Method 2 — Manual install via Device Manager

    If the automatic installer fails, or the device connects/disconnects rapidly, install manually for a stable connection.

    1. Extract CDC drivers: locate the MTK CDC Drivers sub-folder in your extracted driver package.
    2. Open Device Manager — Win+X → Device Manager.
    3. Add legacy hardware: click your Computer Name at the top, then Action → Add legacy hardware → Next.
    4. Select manual option: choose "Install the hardware that I manually select from a list (Advanced)" → Next.
    5. Show all devices → Next.
    6. Browse files: click Have Disk… → Browse → navigate to your MTK CDC Driver folder.
    7. Choose file: select the sub-folder matching your Windows version (Win7 or Win10) and pick the .inf file (e.g. usb2ser.inf, cdc-acm.inf, or mtk_usb_vcom.inf) → Open → OK.
    8. Select driver: choose MediaTek DA USB VCOM Port (or MediaTek Preloader USB VCOM Port) → Next.
    9. Confirm: if Windows Security warns "Windows can't verify the publisher", click Install this driver software anyway.
    10. Finish.

    "Code 10" error: if you see "This device cannot start (Code 10)" in Device Manager after manual install, you can safely ignore it — the driver is loaded manually without an active device connected.

  4. 4. Verify the drivers work

    1. Keep Device Manager open.
    2. Power off your MediaTek device completely.
    3. Hold Volume Up+Volume Down (or just Volume Down, depending on the model) and connect the phone to the PC.
    4. Watch the Ports (COM & LPT) section — you should briefly see MediaTek Preloader USB VCOM (Android) or MTK USB Port appear without a yellow warning icon.

    For modern Helio/Dimensity devices requiring SLA/DAA auth bypass, VCOM drivers alone are not enough. You also need the LibUSB-win32 Filter Driver — see Install LibUSB-win32 Filter Driver.

  5. 5. Troubleshooting

    ProblemFix
    Driver install fails on Win 10/11Disable Driver Signature Enforcement first, reboot, then retry.
    Device appears then vanishes instantlyConnect within 2 seconds of the driver install window opening. Use a USB 2.0 port.
    Yellow warning persistsUninstall device in Device Manager, replug, and let Windows reinstall.
    Code 10 errorSafe to ignore — driver is loaded, just no active device connected.
