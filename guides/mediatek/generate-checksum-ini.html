Generate checksum.ini for MTK Scatter ROM

Type
Step-by-Step Guide
Level
Intermediate
Time
~3 minutes
Applies to
All MediaTek SP Flash Tool firmware
Last updated
YYYY-MM-DD

If you flash customized firmware or read-back dumps, SP Flash Tool often throws BROM ERROR: S_CHKSUM_ERROR (1041) or "checksum file is missing". The tool requires a checksum.ini verification map inside the firmware folder before writing to hardware.

Reference

  1. 1. Why SP Flash Tool needs checksum.ini

    Before writing critical partitions, SP Flash Tool hashes each file and compares against values stored in checksum.ini. If you modify even one byte (e.g. patched boot.img), the hash changes and the tool aborts to prevent bricking. Regenerating the checksum map fixes the mismatch.

  2. 2. Method 1 — Automated one-click generation

    1. Open your MTK firmware folder containing the scatter file.
    2. Check if CheckSum_Gen.exe exists there. If not, copy it from any other SP Flash Tool directory into your firmware folder.
    3. Right-click CheckSum_Gen.exe → Run as Administrator.
    4. A CMD window opens and scans the scatter map.
    5. It computes hash values for every partition image (system.img, boot.img, etc.).
    6. Wait 1–3 minutes.
    7. CMD closes when finished.
    8. checksum.ini appears in the folder — flash will now work.

  3. 3. Method 2 — Manual checksum bypass

    If you don't have the utility:

    1. Open the SP Flash Tool folder.
    2. Open option.ini in Notepad.
    3. Ctrl+F → search CheckSum or chksum.
    4. Find CheckSum=1 and change to CheckSum=0.
    5. Save and relaunch SP Flash Tool — checksum verification is skipped.

    Warning: disabling checksum means corrupted downloads won't be caught. Only use for quick local testing, not for distribution.

  4. 4. Pro tip

    When sharing customized firmware or dumps online, always use Method 1. A valid checksum.ini ensures SP Flash Tool rejects corrupt downloads before writing to hardware.
