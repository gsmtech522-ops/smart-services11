Restore Baseband & IMEI via Maui META

Type
Advanced Guide
Level
Advanced
Time
~20 minutes
Applies to
MTK devices with NVRAM corruption
Last updated
YYYY-MM-DD

Legal warning: only restore the original IMEI of your own device. IMEI modification is illegal in most countries and traceable. IMEI is printed on the box or battery label.

When a MediaTek device experiences complete NVRAM corruption, it reports Baseband: Unknown and IMEI: Null / Invalid. Unlike basic tools that only patch runtime values, Maui META interfaces directly with the baseband processor in low-level META mode, parsing exact database files (BPLGU) and writing recalibration parameters permanently into nvram and nvdata.

Reference

  1. 1. Prerequisites

    • MediaTek CDC Serial & VCOM drivers installed.
    • Maui META Tool (v9.x) or Modem META v10.x (Helio/Dimensity).
    • Official stock firmware matching the target model and build version.
    • BPLGU modem database file from firmware.
    • Original 15-digit IMEI numbers (box or battery label).
    • Quality USB cable + charged device.

  2. 2. Step 1 — Configure Maui META

    1. Extract and launch MauiMETA.exe as Administrator.
    2. Menu Options → check Connect Smart Phone into META Mode.
    3. Set Connection Type → USB COM.
    4. Click Reconnect on the right — the indicator begins flashing green/yellow (listening for device).

  3. 3. Step 2 — Force device into META Mode

    1. Power off the phone completely.
    2. Connect USB.
    3. Boot keys: on most models plugging in auto-powers into META. On locked models, hold Volume Down or Volume Up+Volume Down while plugging.
    4. Windows detects the MediaTek USB CDC port. Phone screen shows logo or static display — META Mode.
    5. Maui META handshakes; the status indicator turns solid yellow/green.

  4. 4. Step 3 — Load BPLGU & rebuild IMEI

    1. From the tool dropdown, select IMEI Download.
    2. Click Change NVRAM Database File.
    3. Browse to BPLGU... in your firmware folder → Open.
    4. In the IMEI Download tab:
      • Enter first 14 digits of IMEI 1 — the 15th checksum digit auto-calculates.
      • For dual SIM, choose SIM 2 tab or enable Dual IMEI → enter IMEI 2.
    5. Click Download To Flash.
    6. Log shows: Write IMEI to NVRAM successful.

  5. 5. Step 4 — Restore baseband calibration

    If "Baseband: Unknown" persists:

    1. Switch the tool dropdown from IMEI Download to NVRAM Editor or Update Parameter.
    2. Click Load From File → select BPLGU if prompted.
    3. Click Upload From Flash to read active NVRAM.
    4. Locate NVRAM_EF_RF_CAL_LID or CALIBRATION_DATA.
    5. Click Write To Flash to force modem re-index.
    6. Click Disconnect to safely exit META and reboot.

  6. 6. Troubleshooting

    Stuck on 'Connect Smart Phone into META Mode'

    Fix: install MTK CDC/VCOM drivers, disable Driver Signature Enforcement, check Device Manager for COM port.

    NVRAM Database File mismatch

    Fix: extract fresh BPLGU from the exact stock firmware matching your current software version, or re-flash full stock firmware via SP Flash Tool first.

    [META] Timeout error

    Fix: on modern SLA/DAA-protected chips, run MTK Auth Bypass tool / MTKClient first to disable security, then retry META connection.
