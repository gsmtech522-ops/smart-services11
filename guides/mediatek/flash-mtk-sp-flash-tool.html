Flash MediaTek Stock Firmware via SP Flash Tool

Type
Step-by-Step Guide
Level
Intermediate
Time
~15 minutes
Applies to
All MediaTek Android devices
Last updated
YYYY-MM-DD

When a MediaTek phone is hard-bricked, stuck in a bootloop, or has severe system corruption, flashing official stock firmware is the ultimate repair. SP Flash Tool is the official MTK software designed specifically for this.

Reference

  1. 1. Prerequisites

    • MediaTek VCOM drivers installed.
    • Official stock firmware with Android_scatter.txt.
    • Latest SP Flash Tool (v5.x or v6.x).
    • MTK Auth Bypass Tool / MTKClient (if SLA/DAA protected).

  2. 2. Step 1 — Launch & load scatter

    1. Open flash_tool.exe as Administrator.
    2. In Download tab, click Choose next to Scatter-loading File.
    3. Select MT6xxx_Android_scatter.txt from the firmware folder.
    4. Partition list appears (preloader, boot, recovery, system, userdata…).

  3. 3. Step 2 — Choose flashing mode

    • Download Only (Recommended): flashes selected partitions without erasing IMEI. Try this first.
    • Firmware Upgrade: for OS version upgrades. Wipes and rebuilds partition layout safely.
    • Format All + Download (DANGER): fully formats the entire flash.

    Warning: Format All + Download erases NVRAM/NVDATA → loses IMEI and baseband. Only last resort.

  4. 4. Step 3 — Trigger & connect

    1. Click green Download button.
    2. Power off the phone.
    3. Hold Volume Down or both volume keys.
    4. Connect USB.
    5. SP Flash Tool detects the device:
      • Red bar: DA download
      • Yellow/purple bar: partition write progress

  5. 5. Step 4 — Complete & first boot

    1. Wait for green checkmark Download OK.
    2. Unplug USB.
    3. Hold Power 10s to boot.
    4. First boot takes 5–10 minutes.

  6. 6. Troubleshooting

    S_BROM_CMD_STARTCMD_FAIL (2005)

    Fix: reinstall VCOM drivers, check COM port conflicts, try direct motherboard USB port/cable.

    STATUS_SEC_AUTH_FILE_NEEDED

    Fix: modern chips require bypass. Run MTK Auth Bypass Tool or MTKClient payload before clicking Download.

    PMT changed for the ROM; it must be downloaded

    Fix: scatter layout doesn't match phone storage. Switch mode from Download Only to Firmware Upgrade.
