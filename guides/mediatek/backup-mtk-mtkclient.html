Backup MediaTek Firmware via MTKClient

Type
Step-by-Step Guide
Level
Advanced
Time
~15 minutes
Applies to
Modern Helio G/P and Dimensity devices
Last updated
YYYY-MM-DD

Modern MediaTek smartphones (Helio and Dimensity) enforce SLA (Serial Link Authentication) and DAA (Download Agent Authentication), blocking traditional tools. MTKClient bypasses these protections at the BROM level, allowing raw partition extraction (boot, recovery, nvram, super, etc.) completely for free.

Reference

  1. 1. Prerequisites

    • MediaTek VCOM / Preloader drivers installed.
    • LibUSB-win32 filter driver or UsbDk installed.
    • MTKClient environment (Python 3.9+).

  2. 2. Method 1 — Backup via MTKClient GUI (easiest)

    1. Open CMD or PowerShell inside your mtkclient folder.
    2. Launch the GUI:
    python mtk_gui.py
    1. Power off the phone.
    2. Hold Volume Up+Volume Down (or test-point for hard-bricked) and connect USB.
    3. MTKClient exploits BROM, bypasses SLA/DAA, and shows device hardware info and partitions.
    4. Go to Read Partition(s) tab.
    5. Select partitions:
      • Critical safety backup: boot, recovery, vbmeta, nvram, nvdata, protect1, protect2, seccfg
      • Full firmware: Select All
    6. Click Read Partition(s) and choose a save folder.
    7. Wait for progress to complete, then unplug.

  3. 3. Method 2 — Backup via MTKClient CLI

    For faster, scriptable backups:

    Dump individual partitions:

    python mtk r boot boot.img
python mtk r recovery recovery.img
python mtk r nvram,nvdata nvram.bin,nvdata.bin

    Full storage dump (all partitions):

    python mtk rl my_backup/

    MTKClient extracts all partitions (preloader, boot, super, userdata, etc.) into the my_backup folder.

  4. 4. Troubleshooting

    ProblemFix
    LIBUSB_ERROR_NOT_SUPPORTED / timeoutInstall UsbDk properly. If using LibUSB, run install-filter-driver.exe and capture the MediaTek port while connecting with volume keys held.
    Device handshake failed / watchdog triggerUnplug, hold Power + Volume Down for 10s to force reboot out of BROM mode, retry.
    Dump halts midwayUse a USB 2.0/3.0 port directly on the motherboard (avoid front-panel hubs) and a high-quality cable.
